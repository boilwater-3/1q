# SAR 显式标定观测内部闭环审批报告

## 1. 审批结论

阶段 61 显式标定观测内部闭环已完成当前平台审批。

- 内部观测对象显式绑定身份、已知 RCS、指定像素、斜距、孔径范围和权重。
- 观测构建只从指定的未归一化复图像像素提取功率，不执行自动全局峰值选择。
- 归一化图像声明、空身份、越界像素、零功率和逆序孔径范围被拒绝。
- 多点观测转换为原子操作，任一无效观测不会部分覆盖调用方已有样本。
- M1 GBP 与 BP 指定像素观测功率一致，并可进入阶段 58 定标核心。
- M4 RCS 反演与联合干扰误差记录保持通过。

## 2. 实现范围

- 扩展内部 `SarRadiometricCalibration` 模块，增加观测请求、不可变观测值和样本转换。
- 扩展基础单元测试与参考场景定标测试。
- 未修改 public API、Session schema、runtime patch 或 replay。

## 3. 验证结果

- 默认环境定标与显式观测测试：`6/6 passed`。
- Conan Eigen 3.3.9 定标与显式观测测试：`6/6 passed`。
- 默认 Windows Debug 完整 CTest：`25/25 passed`。
- Conan Eigen 3.3.9 `sar_cxx11_compat`：`1/1 passed`。

## 4. 冻结边界

- 当前只批准内部显式标定观测。
- 不自动从普通目标列表或全图峰值选择标定器。
- 不批准主瓣积分、亚像素定位、跨周期持久化或有效性阈值。
- 不开放 public 配置、输出 diagnostics 或 replay。

## 5. 下一阶段建议

进入显式观测后续决策门，审计是否可以在不扩大 public 表面的前提下受控接入 Session
内部聚焦管线，或是否应优先建立像素定位与主瓣功率契约。
