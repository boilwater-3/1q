# SAR Omega-K 相对延迟轴后续决策

频谱 inverse-range 变换执行器，显式返回相对延迟轴和距离时域矩阵。

- 收缩频率轴均匀性、相对延迟采样和 FFT inverse/forward 约定已通过验证。

- 参考相位和绝对斜距原点仍缺少独立真值，不能从相对延迟轴推断。
