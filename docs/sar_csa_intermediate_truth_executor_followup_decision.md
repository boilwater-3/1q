# SAR CSA 中间域真值执行器后续决策

日期：2026-06-11

## 1. 决策

CSA 中间域真值执行器保持内部审批工具。完整 CSA 相位公式、固定相位核参考包和逐阶段
复数真值尚未进入仓库，因此完整 CSA 聚焦入口继续后置。

下一建设方向选择 Omega-K 复数 Stolt 插值与中间域参考真值契约。该方向可复用现有
Stolt 几何基础，并独立验证复数插值这一完整 Omega-K 执行链的关键前置能力。

## 2. 审计依据

仓库当前具备：

- CSA 未 shift 频率轴、`D(f_a)`、`alpha(f_a)` 和有效域诊断。
- 显式 FFT/IFFT/相位核操作列表与逐阶段真值执行器。
- 轴、符号、归一化、单位模和首个真值偏差拒绝测试。

仓库当前仍缺少：

- 经审计来源的三个完整 CSA 相位函数。
- 固定标量配置、相位核、操作顺序和逐阶段期望矩阵组成的真实 CSA 参考包。
- 完整 CSA 与 GBP/RDA 的独立中间域和最终质量交叉证据。

## 3. 接入结论

- 不新增完整 CSA 聚焦入口或选择器可用路径。
- 不修改 Session、public API、schema、trace、replay 或 RDA 默认路径。
- 不使用合成操作链测试宣称完整 CSA 公式正确。
- 中间域真值执行器保留为未来公式参考包的强制审批门。

## 4. 下一方向

现有 Omega-K 已冻结 Stolt 映射几何，但复数插值、越界策略和中间域固定真值仍未批准。
下一阶段冻结复数 Stolt 插值的输入轴、映射、插值、越界、确定性和参考真值契约。
