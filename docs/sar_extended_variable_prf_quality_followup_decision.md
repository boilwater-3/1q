# SAR 扩展时变 PRF 质量矩阵后续决策

日期：2026-06-11

## 1. 决策

扩展时变 PRF 重采样能力保持内部参考能力，暂不接入生产 RDA、Session、public API、
schema、trace 或 replay。当前时变 PRF 分支已形成契约、基础、质量矩阵、缺失拒绝和
显式执行器闭环；下一建设方向回到完整 CSA 聚焦的前置缺口，先冻结完整相位函数与
中间域独立参考真值契约。

## 2. 证据边界

- E1-E3/J0-J4 证明小型 L1 参考场景中的周期与随机小抖动可以稳定重采样。
- 当前场景仅有 `9` 个脉冲和 `64` 个距离样本，不代表真实硬件规模与调度。
- 测试只覆盖线性插值、单一 expected interval 和无缺失脉冲允许区。
- public/schema/replay 仍没有显式慢时间请求、执行状态与拒绝传播语义。
- 缺失脉冲修复、真实时变 PRF 调度、NUFFT 和生产阈值均未批准。

## 3. 接入结论

- 不修改固定 PRF Session 与 RDA 默认路径。
- 不将当前测量值解释为通用接入阈值。
- 保持内部执行器与扩展矩阵作为后续时变 PRF 实现的回归证据。

## 4. 下一方向

现有 CSA 仅完成频率几何基础；完整相位函数、处理顺序与独立中间域真值仍缺失。
下一阶段冻结 CSA 完整相位函数与中间域参考真值工程契约，为后续完整 CSA 执行链
实现建立可审计入口。Session、public、Auto 和时变 PRF CSA 继续后置。
