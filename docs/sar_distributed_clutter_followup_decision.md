# SAR 分布式杂波后续决策报告

## 1. 决策问题

复核首批确定性分布式杂波参考矩阵，并在以下候选方向中选择下一阶段：

1. 扩展随机散射点位置、相关杂波或更多网格密度。
2. 建立热噪声与分布式杂波共同存在的 SNR/SCR 二维矩阵。
3. 进入生产杂波、目标可见性阈值或 Auto。

## 2. 当前证据

阶段 52 已证明：

- 规则网格、固定 seed、复系数和遍历顺序可生成逐样本一致的杂波 raw history。
- requested/realized SCR 可通过 raw-history 总能量精确缩放保持一致。
- M1/M4、`3x3/5x5`、双 seed 和 `30/20/10/0 dB` 呈现稳定总体退化趋势。
- RDA、GBP 与 BP 可共同消费同一混合 raw history，BP/GBP 继续逐样本一致。
- 首批场景无回波裁剪，现有 SAR 审批门未回退。

当前仍未证明：

- 空间相关长度、随机位置分布或地物类别统计的合理定义。
- 规则网格结论可外推到相关杂波、海杂波或真实斑点。
- 杂波与热噪声同时存在时，现有比较指标是否仍保持可解释性。
- 通用 SCR 阈值、目标可见性阈值、生产杂波或 Auto 规则。

## 3. 候选方向评估

### 3.1 随机位置、相关杂波或更多密度

更多密度只能扩展当前规则网格趋势，不能解决空间相关模型定义缺失。随机位置和相关
杂波需要先冻结位置分布、相关函数、相关长度和功率归一化口径；当前没有足够证据选择
这些参数。

结论：继续后置，不能直接进入实现。

### 3.2 SNR/SCR 二维矩阵

确定性复高斯噪声与确定性分布式杂波已经分别完成独立契约、实现和验收。两者均注入
raw pulse history，并可由 RDA、GBP 与 BP 共同消费。

二维矩阵可以在不增加新生产模型的前提下，回答“热噪声与分布式背景共同存在时，现有
质量比较是否仍可解释”这一当前证据缺口。

结论：批准作为下一阶段，先冻结独立工程契约。

### 3.3 生产杂波、目标可见性阈值或 Auto

首批规则网格只提供测试侧趋势证据，不具备真实地物散射、绝对功率、辐射定标和统计
代表性。当前不能据此定义生产行为、通用阈值或自动算法选择。

结论：继续禁止。

## 4. 决策

- 下一阶段选择“确定性噪声与分布式杂波 SNR/SCR 二维矩阵契约”。
- 二维矩阵必须复用已验收的噪声与杂波 helper，并明确二者独立 seed 与能量定义。
- 首批矩阵只评估确定性、能量口径和总体趋势，不冻结通用质量阈值。
- 随机位置、相关杂波、更多密度、生产杂波、绝对功率、辐射定标、质量警告、结构化
  拒绝和 Auto 继续后置。

## 5. 下一阶段边界

下一阶段只允许：

- 新增 SNR/SCR 二维矩阵工程契约。
- 选择受控的 M1/M4 子集、有限 SNR/SCR 档位和固定 seed。
- 冻结噪声与杂波独立生成、顺序无关和共同注入 raw history 的口径。
- 冻结比较指标与验收报告要求。

下一阶段不得自动进入实现，也不得修改生产/public/replay 能力。
