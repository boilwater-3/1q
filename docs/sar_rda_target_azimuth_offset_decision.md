# SAR RDA 目标方位偏置误差决策报告

## 1. 决策目标

判断目标方位偏置产生的额外 RDA/GBP 差异是否可以由单一几何量解释，并据此形成生产 diagnostics、质量警告或结构化拒绝。

## 2. 决策矩阵

- 等物理半孔径：`0.4 / 0.8 / 1.6 m`
- 等孔径采样组合：`5@0.2` 对 `9@0.1`、`9@0.2` 对 `17@0.1`、`17@0.2` 对 `33@0.1`
- 归一化目标方位偏置：半孔径的 `0 / 0.25 / 0.5`
- 正负偏置对称性：`-0.4 / -0.2 / 0 / 0.2 / 0.4 m`
- 参考：相同实际轨迹 GBP/BP

## 3. 关键证据

同一物理孔径和目标偏置下，目标相对 broadside 中心切线的非线性相位残差完全一致，但不同采样密度的 NRMS 仍不同：

| 半孔径 | 目标偏置 | 粗采样 NRMS | 细采样 NRMS | 非线性相位残差 |
|---:|---:|---:|---:|---:|
| 0.4 m | 0.0 m | 0.047854 | 0.042218 | 0.000000 rad |
| 0.4 m | 0.2 m | 0.096364 | 0.075643 | 0.000017 rad |
| 0.8 m | 0.0 m | 0.177589 | 0.159746 | 0.000000 rad |
| 0.8 m | 0.4 m | 0.266889 | 0.260633 | 0.000278 rad |
| 1.6 m | 0.0 m | 0.704130 | 0.676300 | 0.000000 rad |
| 1.6 m | 0.8 m | 1.183192 | 1.221633 | 0.004442 rad |

偏置 `-0.4 / -0.2 / 0 / 0.2 / 0.4 m` 的 NRMS 分别为：

`0.260633 / 0.190284 / 0.159746 / 0.190284 / 0.260633`

这证明额外误差与偏置幅值对称相关，但不能由偏置非线性相位残差单独解释。最大候选残差仅 `0.004442 rad`，而对应额外 NRMS 可超过 `0.5`。

## 4. 工程判断

- 目标偏置表示 aperture 支撑相对目标的失衡程度，确实是质量影响量。
- 质量结果同时依赖孔径二次相位跨度、方位采样密度和目标偏置，当前不存在可独立冻结的单变量阈值。
- `RdaConfig` 不包含目标布局；多目标场景也不存在唯一目标偏置，因此该量不适合作为输入级全局 `RdaDiagnostics`。
- 图像峰值位置属于成像后结果，不能反向作为运行前拒绝条件。

## 5. 决策

- 不新增目标方位偏置生产 diagnostics。
- 不批准基于目标偏置的质量警告、结构化拒绝、算法切换或 Auto。
- 保留等物理孔径、等偏置和正负对称性矩阵作为回归证据。
- 下一阶段进入 Phase 2 参考级成像与算法对比闭环综合再审批，统一判断当前证据覆盖和后续扩展优先级。
