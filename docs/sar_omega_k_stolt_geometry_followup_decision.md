# SAR Omega-K Stolt 几何后续决策

## 1. 决策结论

Omega-K Stolt 几何基础保持为独立内部诊断能力。复数 Stolt 插值、参考相位、完整聚焦
和内部选择器接入继续后置。下一条 SAR 雷达组件建设线选择自聚焦残余相位误差与参考
真值工程契约。

## 2. 证据审计

仓库当前具备：

- 未 shift 二维频率轴和双程波数约定。
- 传播色散有效域与 Stolt 源距离频率查询。
- 色散无效点、越支持区查询和最大 shift 诊断。

仓库当前不具备：

- 经审计的复数 Stolt 插值参考结果和幅相误差阈值。
- 越支持区裁剪、填零或目标网格收缩策略。
- 完整 Omega-K 参考函数相位和固定二维频谱中间结果。
- 可重复运行的独立 Omega-K 参考脚本。

## 3. 接入决策

- 不实现复数 Stolt 插值或完整 Omega-K 聚焦。
- 不把 Omega-K 加入内部聚焦选择器。
- 不新增 public API、Session、schema、trace、replay 或 runtime patch。
- 不修改 RDA 默认路径。

## 4. 下一方向

此前聚焦能力审计指出，自聚焦缺少可观测残余相位误差模型、PGA 输入支持区和独立真值。
下一阶段先冻结残余相位误差注入、估计目标、不可观测分量和验收边界，不直接实现通用
自聚焦或接入 Session。
