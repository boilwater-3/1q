# Navigation 算法

## 算法清单

| 算法 | 输入 | 输出 | 证据 |
|---|---|---|---|
| 多边形牛耕式扫描线覆盖 | 多边形 LLA 顶点 + 扫描配置 | 交替方向扫描航点序列 | `src/navigation/AreaCoveragePlanner.cpp`；`tests/unit/navigation/navigation_area_coverage_planner_test.cpp` |
| 圆形单环/同心圆盘旋 | 圆心 LLA + 半径 + 取点数/环数 | 外→内环均布航点序列 | 同上 |

## 1. 多边形牛耕式扫描线覆盖

实现步骤（全部在 `src/navigation/AreaCoveragePlanner.cpp` 匿名命名空间内）：

1. 校验：顶点 ≥ 3、LLA 合法、间距 > 0、扫描航向有限、模式与区域形态匹配；
   非法 → 空计划 + 告警日志。
2. 以顶点经纬度平均为 ENU 原点（首期不按面积加权），`TryLlaToEnu` 投影全部顶点。
3. 按扫描航向旋转到扫描系：u 沿扫描方向、v 为扫描线法向（扫描线 = v 常量）。
4. 扫描线取 v_min + 半间距偏移逐条推进（**半偏移规避扫描线恰穿极值顶点**；
   末条线若恰落于 v_max——跨度为间距整数倍时——下压一个容差，避免与极值边
   重合产生零交点而被静默跳过）。
5. 每条线与多边形边求交（半开规则：两端点一个严格在上、一个不在上时计一次），
   x 排序后两两配对为段。
6. 牛耕式：段内方向逐线翻转；反向线自右向左取段，保证与上一条线的过渡最短。
7. 反旋转 + `TryEnuToEcef`/`TryEcefToLla` 回 LLA，高度/速度/到达半径取自配置。
8. 间距大于区域跨度时扫描线循环为空 → 退回区域中线单条扫描线；
   中线也产生不了任何扫描段（退化多边形，如近共线顶点）→ 空计划 + 告警。

### 实现边界

- 多边形为**简单多边形**假设（凸/凹均可）；自交多边形结果未定义。
- 顶点恰好落在扫描线上时按 even-odd 语义计一次交点；切点（两侧同侧）产生零长段，
  属已知限制，半偏移起始使其仅在巧合下发生。
- 平面几何使用 ENU 切平面近似：大区域（百公里级）的平面误差随跨度增长，
  首期不处理（区域覆盖场景通常为局域）。

### 反直觉点

- 相邻航点不总是同一条扫描线：段内两航点属于当前线，**跨线过渡航段（斜线）**
  隐含在序列中——执行侧按顺序直连即可。
- 间距大于区域跨度时**不会**返回空计划，而是退化为中心线单条扫描线
  （保证任何合法输入都有可执行的航路）。
- 近共线（近零宽）多边形产生**退化短段航路**而非空计划——所有顶点重合的
  点状多边形才会返回空计划（已知限制，见 boundaries.md 非目标 3）。

## 2. 圆形单环/同心圆盘旋

实现步骤：

1. 校验：半径 > 0、圆心合法、取点数 ≥ 3、环数 ≥ 1。
2. 外→内逐环：第 j 环半径 = r × (环数 - j + 1) / 环数。
3. 每环自正北起逆时针均布 `orbit_segments` 个点（ENU 平面圆 → 回变换 LLA）。
4. 环间以直连过渡（上一环末点 → 下一环首点，隐含于序列）。

### 反直觉点

- 同心圆半径是**等差递减**（r, r·(k-1)/k, …, r/k），不是按间距配置；间距驱动的
  环布置留待后续（YAGNI）。
- 盘旋起点固定在正北，无起始方位配置（首期最小面）。

## 校验与失败语义

- 所有输入校验失败统一返回**空计划 + `PROJECT_LOG_WARN`**（不抛异常，库内无异常纪律）。
- 航点回变换失败（输入合法时不应发生）跳过该点并告警。
