# SAR Omega-K 共同支持窗口后续决策

日期：2026-06-11

## 1. 决策

批准下一阶段建立内部显式 Stolt 目标网格收缩请求与执行边界。请求只能使用共同支持
诊断返回的最大连续窗口，必须显式返回收缩后的目标距离频率轴和原始列索引。

不批准自动裁剪、默认网格变化或完整 Omega-K 聚焦。

## 2. 依据

- 共同支持诊断能确定所有方位 Doppler 行均可查询的连续目标频率窗口。
- 保留原始列索引可审计未 shift 网格到收缩频率网格的映射。
- 裁剪后输出列数与距离频率轴发生变化，必须由显式内部请求表达，不能隐式修改。
- 参考相位、二维 IFFT、空间域距离轴和幅度归一化仍未冻结。

## 3. 批准边界

- 允许显式请求选择共同支持窗口并提取查询矩阵和目标频率轴。
- 允许对提取后的查询矩阵调用已审批复数 Stolt 插值器。
- 请求、收缩和插值失败时输出原子为空。
- 不修改输入频谱、几何诊断或原始目标网格。

## 4. 后置内容

- 自动选择窗口、非最大窗口、非连续列拼接和越界填零。
- 收缩后二维 IFFT、空间域距离轴定义、完整 Omega-K 聚焦与生产接入。
