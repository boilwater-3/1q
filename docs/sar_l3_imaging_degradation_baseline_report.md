# SAR L3 Raw Echo 与成像退化基线报告

## 1. 审批结论

L3 航路点轨迹 raw echo 与成像退化基线已完成当前平台审批。

- L3 实际轨迹生成点目标 raw echo：通过。
- 现有 L1-RDA 处理 L3 raw echo 时产生显著可测退化：通过。
- GBP 使用 L3 实际逐脉冲位置后仍能将目标聚焦到预期邻域：通过。
- public L3、二阶补偿、BP 和 Auto：不批准，继续后置。

## 2. 确定性场景

- 使用已审批的 `9x9` RDA/GBP 单点参考场景。
- L1 为匀速直线轨迹。
- L3 在孔径中点进入第二航段，并在孔径末端形成 `3 m` 横向偏移。
- 脉冲时刻保持固定 PRF，确保本阶段只改变轨迹，不混入时变 PRF 影响。

## 3. 质量证据

| 比较 | 单位能量 NRMS | 相干相关系数 |
|---|---:|---:|
| L1-RDA 相对 L1-GBP | `0.042218` | `0.999109` |
| L3 raw echo 经 L1-RDA，相对 L3-GBP | `0.501878` | `0.874059` |

L3-GBP 峰值仍位于预期目标像素邻域，证明 raw echo 与实际轨迹可被任意轨迹参考聚焦器一致消费。

## 4. 工程发现

- 现有 L1-RDA 的匀速直线假设不能直接扩展到折线 L3 轨迹。
- 使用 `33x9` 窗口时，现有 L1-RDA/GBP 基线本身已出现较大差异，不能将该场景用于隔离 L3 轨迹影响；本阶段因此保持在已有跨算法一致性证据的 `9x9` 基线上。
- 当前证据只证明 L3 会导致 L1-RDA 退化，不证明一阶补偿、二阶补偿或 BP 的必要性与充分性。

## 5. 验证结果

- 默认与 Eigen 3.3.9 L3/GBP/补偿/RDA/Session 过滤测试：各 `32/32 passed`。
- `ctest -L sar_ci`：`4/4 passed`。
- `ctest -L sar_performance`：`1/1 passed`。
- Eigen 3.3.9 `sar_cxx11_compat`：`1/1 passed`。
- `git diff --check`：passed。

## 6. 下一阶段建议

优先审计现有单参考点一阶运动补偿对 L3 的适用性，并使用 L3-GBP 量化补偿后残余误差。只有一阶补偿不足的证据成立后，才讨论 BP 或二阶补偿。
