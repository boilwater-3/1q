## 3. 验证过程中发现并已修复的缺陷（3 项）

1. **推演/精度验收行恒为 `周期=0 时间=0.000s`**：`PrecisionEvaluationSession` 组装推演输入时
   未填 `InferenceTrackState::sim_time_sec/input_cycle_index`——多文件对拍字段全废，且关机状态机
   dt≡0（加速度通道失效）。已填 `周期×dt`；修复后行首 `仿真时间=3.000s 仿真周期=3` 正常。
2. **条1 双星误差同值**：随机盐未混卫星位置，同周期两星抽样相同（首版日志两星均 12.2m）。
   已将卫星 ECEF 混入盐值，修复后两星独立（−41.3 / 44.7m）。
3. **RIR 条17 双括号 + 条16 注释误挂**：`FormatVec3` 自带括号导致 `((-6034577.1,…))m`；
   马氏距离²说明括号挂在量测明细尾部易误读。均已修正。

## 4. 整体异常扫描发现的其他事项（6 项，未改动）

1. **UKF 初期暂态量大**（双星场景，既有行为）：滤波速度从 0 起步，前 10 周期位置误差 10⁶ m 量级、
   接力行 `加速度模≈速度模`（第 2 拍差分基线为零所致）；60 周期收敛到位置 ~4km / 加速度 ~80m/s²。
   代价是 关键精度指标 的速度 RMSE（5517 m/s）与发射点 RMSE（498 km）被初期样本主导。
   建议（后续项）：精度统计剔除前 N 收敛周期，或调 `track_initial_*_std` / 过程噪声。
2. **关机点状态机对无助推目标会误确认**（既有行为）：中段弹道目标能量本应恒定，滤波噪声触发
   "能量上涨≥2 拍"助推通道 → 第 3 拍即确认 `关机点时刻=2.0s`。状态机阈值针对助推段设计；
   对全程无助推目标建议走 kBeforeWindow（窗口外）路径——需与甲方确认口径后另改。
3. **`单步执行时间=暂无` 保留 2 处**（RIR/SBIRS 各一）：批注10 明确暂不处理（条23）。
4. **sbirs `协同工作机制 按威胁等级抢占=无` 恒定**（320 行）：威胁评分在决策层、库内无抢占，
   既有裁定如实标注，非缺陷。
5. **rir_jammed_scan 全程无确认航迹/识别**（场景数据特性）：Pd≈0.052（受干扰），400 周期
   `大类=未知` 998 行、`型号=无`、调度 `跟踪×0`。条19/20 的真实类别名（战斗机等）在该场景
   无法展示——如需向评审演示类别输出，建议补跑无干扰场景（如 `rir_long_range_scan`）。
6. **RIR 场景融合句柄为回退形式 `实体2`**：通用 `fusion_component` 未注入
   `FusionConfig::source_names`（按设计回退）；如需可读名，在该场景装配处按平台填入即可。
