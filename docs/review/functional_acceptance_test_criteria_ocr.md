# 功能验收测试判定标准

> **通用判定规则**：各测试项以指定日志文件中**能否记录**对应数据为准——能记录视为**通过**，否则视为**不通过**。

## 0. OCR 文件名 ↔ 仓库落盘

| OCR / 规范文件名 | 仓库实际路径 | 编译开关 |
|---|---|---|

  - **示例**：
    ```text
    仿真时间=1.000s 仿真周期=1 [探测角度计算功能测试] 验收内容：目标ID=1001 量测方位/俯仰=(12.312,18.491)°
    ```
