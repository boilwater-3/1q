# 雷达信号处理测试设计对照（2026-08-22）

## 0. 定位与结论

两张图是**同一份**测试设计：主题以「…功能测试」收尾，指标原句都写成「`RadarSingalProcessingDateFlow.csv` 文件中能够记录…」（原文拼写如此）。本档**丢掉指定 CSV 落盘约束**，只统计冒号后的指标本身。

原文只覆盖雷达信号处理 / 跟踪识别 / 调度，**没有**红外、融合、推演、精度、性能测试主题。按清单验收类，全部归入 `雷达·探测` / `雷达·跟踪识别` / `雷达·调度`。

结论：

- 主题 17 个（信号增益在图 1 写「信号增益」、图 2 写「目标信号增益」，按图 2 更完整的标题合并）。
- 原文指标行 44 条（搜索主题 3 条原句带「视为通过，否则视为不通过」，仍按指向 / 扫描调度 / 检测量测三条计）。对照表把「散射中心和轮廓特征、识别类别」拆成明细 / 类别，共 45 行。
- 能对上清单且清单写「能输出」（含配置派生 / 摘要 / 统计量）：**24**。
- 能对上清单但清单已标 **不能输出**：**8**。
- 清单没有对等指标，或只部分对上（字段集合不够）：**11**。
- 不在雷达验收项、指标在其他层（原文测试设计归类有误）：**2**。

没有的原因不是「漏接线」，而是库约束与这份测试设计不一致：库是效能级 SINR 账本 + 统计级 CFAR + 双通道极化特征，不是 MTI/MTD 滤波器组、CA-CFAR 或 IQ 回波。

### 3.1 MTI / MTD：主链仍无通路，验收旁路可派生（10 条）

检测主链仍是分项 SINR 账本 + 四个 dB 偏置，**不**把 L1 回灌 Pd。2026-08-22 起验收旁路按冻结公式写 8 路派生字段，标明「验收派生」「未进SINR」，不写「经处理后」。不得把聚合功率均分 8 路。

| 原文指标 | 现状 |
|---|---|
| MTD 增益 | 验收派生 MTD 增益（选中路 DFT 响应）；未进 SINR |
| 真实 MTI 增益 | 验收派生 MTI 增益（2 脉冲 \|H(f_d)\|²）；主链仍用杂波抑制偏置 |
| 各多普勒通道噪声功率 | 验收派生 8 路（热噪声×2/8） |
| MTD 等效噪声功率 | 验收派生选中路噪声 |
| MTD 各通道杂波剩余分布 | 验收派生（高斯谱 × MTI × DFT） |
| MTD 处理后杂波抑制比 | 主链仍只写偏置总抑制比；旁路写剩余瓦数与 8 路，不另造「处理后抑制比」 |
| MTI 后干扰剩余功率 | 有链路多普勒时验收派生；否则 `无` |
| MTD 各通道干扰分布 | 有链路多普勒时验收派生；否则 `无` |
| MTD 处理后干扰总抑制比 | 不写该项名；不把偏置顶替为处理后抑制比 |
| 总干扰抑制增益（处理后） | 主链仍只写干扰抑制偏置 |

### 3.5 极化是双通道能量，不是散射矩阵（5 条）

库识别观测只有 `energy_difference_db` / `relative_difference_db` / `energy_sum_db` / `quality`。Sinclair S 与行列式、Span、去极化、本征极化角 / 椭圆率只在验收旁路构造，不进识别。

| 原文指标 | 原因 |
|---|---|
| 极化散射矩阵行列式 | 无散射矩阵 |
| 功率迹（Span） | 无矩阵迹；能量和是双通道效能量，不是 Span |
| 去极化系数 | 无该导出量 |
| 本征极化方向角 | 无 Huynen / 本征极化分解 |
| 本征极化椭圆率 | 同上 |

能写的近邻：极化差 / 相对 / 和、目标类别、置信度。

识别观测仍是两路实数 RCS 三能量。2026-08-22 续裁走 **L2 验收旁路**（与 MTI/MTD 同模式）：公开样本可加交叉极化与 HH–VV 相位（`has_*` 显式开关），不改提取器 / 匹配 / 模板。最近邻样本两个 `has_*` 都为真才按 Sinclair S 写「验收派生」五字段并标明「未进识别」；否则五行同句暂无，**不回退 L1 对角实矩阵**。

| 验收派生字段 | 公式 |
|---|---|
| 功率迹 | `σ_hh + σ_vv + 2 σ_hv`（不是 `energy_sum_db`） |
| 行列式 | `|det(S)|`，`S` 按 HH/VV、HV=VH、φ_hv=0 构造 |
| 去极化系数 | `2 σ_hv / Span`（Span=0 失败 → 暂无） |
| 本征极化方向角 | Graves `G=SᴴS` 最大特征向量，ρ=V/H，`ψ=½ atan2(2 Re ρ, 1−|ρ|²)` |
| 本征极化椭圆率 | `τ=½ asin(2 Im ρ / (1+|ρ|²))`（度） |

L3（IQ 协方差）不实施。识别结论仍只用极化差 / 相对 / 和。
