## 2. 阶段 5：大气模型几何路径精细化（方向规划定稿，待实施）

**状态：未实施。以下为已定稿的决策基线（用户确认），未来实施时以此为准。**

- **几何路径量 = 大气壳层路径长度 d_atm**：LOS 与「地球半径 + 大气顶高度」球壳
  求交的大气内路径长度（二次方程解析解）。不用 ECI 极坐标 el（相对赤道面，
  非大气科学视线仰角，语义错位）；不做纯距离指数衰减。
- **d_max 反解**：以该目标当前 LOS 几何算出的 τ 为常数反解，不做路径自洽迭代
  （文档注明近似语义：对远距离目标略乐观/悲观）。
- **校验范围**：仅新增字段（参考路径长度、大气顶高度），不动既有环境字段，
  沿用运行期 clamp。
- **模型方向**：`SbirsEnvironmentConfig` 新增 `atmospheric_path_reference_km` /
  `atmospheric_shell_height_km` + 几何修正开关（默认关闭 → 既有 235 例单测
  逐位不变）；`τ_path = base^(d_atm/d_ref)`（Beer-Lambert 式），`τ_eff =
  clamp(τ_path) × (1 − A_total)`；波长维度保持单一波段（简易模型边界）。
- **语义边界**：`base_atmospheric_transmittance` 从「总透过率标量」变为「参考路径
  长度下的透过率」；开关默认关闭时语义不变。验收基准：地平线方向 d_atm ≫
  星下点方向 → τ 更小 → d_max 更小。
- **实施后收尾**：指标 3 判定更新为「✅ 满足（τ 随几何路径）」；契约测试固化
  六项指标。
