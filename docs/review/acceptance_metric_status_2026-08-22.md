## 2. 没有 —— 日志如实写 `暂无` / `无`

### 2.1 整项不能输出（6 项）

### 2.3 反向处理（拒绝造假）

- 「可支持连续运行次数」**不虚构**「上限 10000」，只写本会话实际已运行周期数 + 状态=正常。
- 雷达 KF/IMM 行不得冒充 UKF；未跑融合引擎的会话融合项按整项缺处理。

## 3. 只为了应付验收的 —— 验收派生旁路

共同特征：标明**「验收派生」**并注明**未进SINR / 未进识别 / 未进判决**；
关 `ONEQ_ENABLE_RIR_ACCEPTANCE_LOG` 等开关时宏与派生一并剪除；
不影响 Pd、检测、关联、调度、识别分数（关开关同场景数值一致）。
验收答辩若被追问「这些数对检测/识别有没有影响」——答案是没有，来源档已写明。

### 3.1 MTI/MTD 全家（L1 旁路，`src/common/radar/MtiMtdAcceptanceBank`）

覆盖行：MTI 增益、MTD 增益、各多普勒通道噪声功率、各通道杂波剩余分布、MTD 等效噪声功率、
MTI 处理后杂波剩余功率、MTI 处理后干扰剩余功率、各通道干扰功率分布。

- 通道数 N=8、2 脉冲 MTI、杂波谱宽 σ_v=0.25 m/s —— **核内写死常量，不可配**。
- 主链 SINR/CFAR/Pd/关联/航迹完全不消费这些数值。
- 冻结依据：`rir_mti_mtd_acceptance_sidecar_freeze_2026-08-22.md`（禁止把功率均分 8 路冒充通道）。

### 3.2 抑制比三项

MTD 杂波抑制比、MTD 干扰抑制比、总干扰抑制增益 —— 复用 MTI/MTD 核按公式算出，标「未进判决」。
输入或剩余非正写 `暂无`；无干扰单音写 `无`。
冻结依据：`rir_acceptance_remaining_metrics_sidecar_freeze_2026-08-22.md`。

### 3.3 统计检测门限 / 结果 / 概率

`RadarEquations::ComputeThreshold(pfa, N)` 公式值，N=effective_pulse_count，标「未进判决」。
不改 `DetectResolvedCell`，不做 CA-CFAR。

### 3.4 极化 L2 五字段（`src/remote_identification_radar/runtime/PolarizationAcceptanceS`）

功率迹、散射矩阵行列式、去极化、本征极化方向角/椭圆率角。

- 识别主链只用三能量（差/相对/和）；这五行纯旁路，标「未进识别」。
- 需样本同时给 `has_cross_pol` 与 `has_phase_vv`，缺任一五行一起写 `暂无`，**冻结不许回退** L1 恒 0。
- 冻结依据：`rir_polarization_l2_acceptance_sidecar_freeze_2026-08-22.md`。

### 3.5 波位排列表 / 扫描轨迹序列（`rir_scan_pattern.csv`）

由公开配置经 `BuildAbsoluteScanWaves` **确定性重建**的整表，不是运行时实测产物。
日志另写本周期序号与下一波位；指定任务时注明「本周期指向=指定，表为扫描序列」。

### 3.6 散在公式派生量

| 派生量 | 公式/约定 |
|---|---|
| 加速度（融合/接力/UKF） | 相邻周期速度差商 Δv/Δt |
| CEP50 | 0.5887 × 水平 RMSE（圆高斯） |
| 95% 置信区间 | mean ± 1.96·RMSE/√n |
| 误差椭圆（轨迹预报） | 半长=半短=1σ、方位=0（各向同性） |
| 置信度（发射点/落点预报） | 1σ 高斯约定写 0.68 |
| 事件等级（特殊事件） | 首次=1、中断=2、突变=3 |
| 轨迹突变判据 | 相邻周期 \|Δv\|/max(\|v\|,ε) > 0.2 |
| 航向 | atan2(北向速度, 东向速度) |
| 融合 ECEF 位置 | 由公开 LLA 换算 |
| 窄场最大探测距离 | 宽场辐射公式对窄场参数重算一遍 |
| 卫星定位误差等效角 | 由 `orbit_sigma` 抽样派生 + 会话内均值/RMS |
| 卫星错误三维 ECEF | 同一抽样角经参考距离弧长映射至本地水平面（东/北）叠加真值，径向不扰动（2026-08-22 甲方批注「映射的错误三维」） |
| 三轴位置误差 | 估计 ECEF − 真值 ECEF 转 ENU 后分轴 RMSE |
| AHP 等级 | A≥0.85 / B≥0.70 / C≥0.55 / D<0.55 阈值分档 |

### 3.7 占位行

集群目标识别、关机点预测、多模型并行加载及库内计时三项：对应层验收文件写 `暂无` 占位行，
保证交付时按原文名能搜到条目。

## 4. 一句话总结
