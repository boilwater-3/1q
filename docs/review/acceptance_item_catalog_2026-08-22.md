# 验收项统计（2026-08-22）

本档把验收清单收成「一项三块」，给验收日志接线用。验收旁路不改仿真主链。代码已按本档落盘（四段同一行、按层分文件）。

对照：功能是否实现见《红外载荷与远程识别雷达需求源码对应关系.md》；本档只答「验收文件里能不能看见、看见什么」。

清单里不只有红外载荷和远程识别雷达。融合、推演、精度评估等项属于其它层，**不要写进** `sbirs_acceptance.log` / `rir_acceptance.log`，各写各层自己的验收文件。

## 0. 怎么读

**目标日志形态**（四段同一行；**一条原文指标一行**。`[验收项：]` 用原文指标名，交付时按该名搜索即可）：

```text
仿真时间=1.000s 仿真周期=1 [验收项：MTD增益] 验收内容：目标ID=1001 6.021dB
```

验收内容只写数值或 `无`/`暂无`。不写「验收派生」「未进SINR」「未进识别」「未进判决」「占位」及原因括注。

**第 2 块口径**（工程清单，不进交付日志正文）：

- 能输出：主链已有的量，以及能用已有量按公式算出来的量（必须写入日志）。
- **不能输出**：库里没有源数据、也没有可套的公式。整项都没有时，第 3 块验收内容写 `暂无`。

**落盘（按实现层，不按验收原文章节往两个传感器文件里塞）**：

| 验收类 | 实现层 | 验收日志文件 |
|---|---|---|
| 红外·探测、红外·宽窄视场 | `sbirs_sensor` | `sbirs_acceptance.log` |
| 雷达·探测、跟踪识别、调度 | `remote_identification_radar` | `rir_acceptance.log`；三维方向图另写 `rir_antenna_pattern.csv` |
| 融合跟踪（含 UKF、协同融合、接力里能写的运动/融合结果） | `fusion` | `fusion_acceptance.log` |
| 轨迹推演（轨迹/落点/发射点/落点发布；特殊事件里的推演侧） | `target_inference` | `inference_acceptance.log` |
| 特殊事件里的首次探测/跟踪中断 | `sbirs_sensor` 生命周期 | `sbirs_acceptance.log` |
| 精度评估（关键精度、层次分析法） | `precision_evaluation` | `precision_acceptance.log` |
| 性能测试 | 各层自己 | 写入**该层**验收文件（红外计时进红外文件，雷达计时进雷达文件）；不集中造一份假总表 |
| 集群目标识别、关机点 | 无对应层 | 不写文件，或只在规划档保留 `暂无` |

开关按层各开各的（`ONEQ_ENABLE_SBIRS_ACCEPTANCE_LOG` / `ONEQ_ENABLE_RIR_ACCEPTANCE_LOG` / `ONEQ_ENABLE_FUSION_ACCEPTANCE_LOG` / `ONEQ_ENABLE_INFERENCE_ACCEPTANCE_LOG` / `ONEQ_ENABLE_PRECISION_EVALUATION_LOG`），默认 OFF。精度评估写入 `precision_acceptance.log`，不再往红外/雷达会话开头抄示意。

原文 OCR：宽/展市场→宽/窄视场；拖把量→脱靶量；大负面→大幅面；斜方差→协方差；弟弟目标→低动态目标；dd 模型→弹道模型；扫描操角→扫描掠角；UK f→UKF；规模目标识别→集群目标识别。

仍按下列理解（不同意再说）：原文要「控制台打印」的，改成该层验收文件同一行，不另开 stdout。

## 2. 红外·探测（`sbirs_acceptance.log`）

## 6. 精度评估（`precision_acceptance.log`）

### 关键精度指标
- 验收类：精度评估
- 能/不能：能输出 PrecisionEval 的 mean/RMSE/P95/max。三轴位置误差由（估计 ECEF−真值 ECEF）转到 ENU 后分轴 RMSE 派生。CEP50=0.5887×水平 RMSE（圆高斯）。95% 置信区间=mean±1.96×RMSE/√n。**不能输出**：误差源贡献率（无分源灵敏度模型）。
- 达标日志：`仿真时间=0.000s 仿真周期=0 [验收项：关键精度指标] 验收内容：东/北/天RMSE=(90,80,150)m 距离RMSE=180m 方位/俯仰RMSE=(0.010,0.012)° 合成RMSE=200m CEP50=118m 位置误差95%CI=[90,450]m 误差源贡献率=无`

### 层次分析法
- 验收类：精度评估
- 能/不能：能输出各层权重、底层评分、综合分、CR、分项贡献。等级由综合分阈值派生（A≥0.85 / B≥0.70 / C≥0.55 / D<0.55）。贡献度排序按 权重×底层分 从高到低。**不能输出**：独立多层树（只有一层准则）。
- 达标日志：`仿真时间=0.000s 仿真周期=0 [验收项：层次分析法] 验收内容：准则层权重=(0.200×5) 底层分=(0.85,0.78,0.90,0.72,0.70) 综合分=0.790 等级=B 贡献排序=速度>测角>双星>落点>发射点 CR=0.000`
