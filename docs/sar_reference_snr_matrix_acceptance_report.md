# SAR 确定性噪声与 SNR 鲁棒性参考矩阵审批报告

## 1. 审批结论

测试侧固定 seed 复高斯噪声 helper 与首批 M1/M4 SNR 鲁棒性矩阵完成当前平台审批。

- 同输入、SNR 和 seed 的 noisy raw history 逐样本一致。
- 不同 seed 的 noisy raw history 不同。
- 噪声按总能量精确缩放，realized SNR 与 requested SNR 一致。
- RDA、GBP 与 BP 共同消费同一 noisy raw history。
- BP 与 GBP 在所有 noisy 场景下继续逐样本一致。
- 不批准生产噪声模型、public 配置、质量阈值、警告、拒绝或 Auto。

## 2. 矩阵范围

- 场景：M1 中心单点、M4 二维分离多目标。
- SNR：无噪声、`30/20/10/0 dB`。
- seed：`17/29`。
- 注入位置：raw pulse history，位于距离压缩和所有成像算法之前。

## 3. 关键结果

seed `17` 下 RDA noisy 相对 GBP noisy：

| 场景 | SNR | NRMS | 相干相关系数 |
|---|---:|---:|---:|
| M1 | 30 dB | 0.042180 | 0.999110 |
| M1 | 20 dB | 0.044864 | 0.998994 |
| M1 | 10 dB | 0.070107 | 0.997543 |
| M1 | 0 dB | 0.187519 | 0.982418 |
| M4 | 30 dB | 0.079274 | 0.996858 |
| M4 | 20 dB | 0.079116 | 0.996870 |
| M4 | 10 dB | 0.092969 | 0.995678 |
| M4 | 0 dB | 0.201058 | 0.979788 |

seed `29` 得到相同总体趋势；`0 dB` 下 M1/M4 NRMS 为 `0.175423/0.199308`。

clean/noisy 对比误差随 SNR 降低单调增加。`0 dB` 的跨算法结果越过当前无噪声参考矩阵使用的 `NRMS < 0.1` 与 `correlation > 0.99` 门，但这不构成算法失效结论，因为当前尚未冻结带噪场景质量门。

## 4. 工程判断

- 当前跨算法比较在 `10-30 dB` 首批场景中仍保持较高一致性，`0 dB` 明显受噪声主导。
- RDA clean/noisy 使用完整输出图，GBP clean/noisy 使用受限小场景图；二者的绝对噪声鲁棒性数值不能直接横向比较。
- RDA noisy/GBP noisy 使用相同小窗口，可用于跨算法一致性研究。
- 两个 seed 足以证明首批趋势不是单一序列偶然结果，但不足以冻结统计质量阈值。

## 5. 冻结边界

- helper 与矩阵只存在于测试支持层。
- 不增加生产噪声/杂波模型、绝对功率或辐射定标语义。
- 不增加 public API、Session diagnostics、runtime patch 或 replay。
- 不启用 Auto、质量警告、结构化拒绝或尺寸扩展。

## 6. 后续决策

下一阶段应评估：

1. 是否需要将相同输出窗口的 clean/noisy 比较冻结为统一 SNR 质量口径。
2. 是否需要扩展更多 seed 与中间 SNR 档位。
3. 是否有证据进入确定性分布式杂波模型。

在上述问题完成前，不批准通用 SNR 通过阈值。
