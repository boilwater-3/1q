# SAR 辐射定标后续接入决策

## 1. 决策结论

阶段 59 决定不立即将辐射定标接入 public Session diagnostics。下一阶段先冻结显式标定
观测工程契约，定义标定目标选择、未归一化图像功率提取、斜距来源和定标结果生命周期。

完整雷达方程系统因子、有效性阈值、runtime patch 和 replay 继续后置。

## 2. 当前已具备能力

- public cycle 输入已有点目标位置与 RCS。
- hardware 配置已有载频与天线增益等部分参数。
- Session 内部可以生成 raw history 和聚焦图像。
- 内部定标模块可以基于图像功率、斜距和已知 RCS 完成闭环。

## 3. 直接接入阻塞项

- 没有显式标定目标标识或选择策略，不能可靠区分普通场景目标与标定器。
- public 输出仍为摘要级，不暴露定标使用的未归一化聚焦像素功率。
- 没有冻结目标像素定位、主瓣功率或峰值功率的提取口径。
- 没有冻结跨周期定标结果的生效、失效和替换规则。
- 当前缺少完整发射功率、双向增益、系统损耗和图像处理增益语义。
- 当前联合干扰矩阵只支持记录误差变化，不支持定标有效性阈值。

## 4. 候选方向判断

### 受控 public Session diagnostics

暂缓。在标定观测来源和生命周期未冻结前，公开定标因子或辐射误差会形成无法审计的
输出语义。

### 完整雷达方程系统因子

暂缓。需要统一发射功率、增益口径、系统损耗和图像处理增益；当前只具备部分硬件参数。

### 标定有效性语义

暂缓。SNR 门、边缘门和残差门需要更完整的场景矩阵与误差证据。

### 显式标定观测契约

选择。先定义内部观测对象与确定性提取口径，可以连接现有聚焦链路和定标核心，同时不
提前扩大 public/replay 表面。

## 5. 下一阶段边界

- 首批仍为内部能力，不修改 public API、Session schema 或 replay。
- 显式提供已知 RCS、斜距、未归一化图像功率和观测标识。
- 冻结单点峰值功率与可选主瓣积分功率的边界，但首批只批准峰值功率。
- 不自动从普通目标列表选择标定器。
- 不冻结 SNR、边缘距离、残差或联合干扰有效性阈值。
