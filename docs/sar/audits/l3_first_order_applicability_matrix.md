# SAR L3 一阶运动补偿适用边界矩阵报告

## 1. 审批结论

当前 `9x9` 固定 PRF 小场景的一阶运动补偿适用边界矩阵已建立，并识别出明确通过区与明确失效区。

- 孔径末端横向偏移 `0/1/3/6 m`：当前质量门通过。
- 孔径末端横向偏移 `12 m`：当前质量门失败。
- 目标偏离中心补偿参考点越远，空间变化残余斜距误差持续增大。
- 失效区支持进入 L3 专用 BP 研究；不支持直接批准 public L3、二阶补偿或 Auto。

## 2. 转弯幅度矩阵

一阶补偿后相对 L3-GBP：

| 孔径末端横向偏移 | NRMS | 相干相关系数 | 当前门 |
|---:|---:|---:|---|
| `0 m` | `0.042218` | `0.999109` | 通过 |
| `1 m` | `0.145803` | `0.989371` | 通过 |
| `3 m` | `0.185881` | `0.982724` | 通过 |
| `6 m` | `0.176972` | `0.984341` | 通过 |
| `12 m` | `0.386100` | `0.925463` | 失败 |

当前通过门为 NRMS `< 0.25` 且相干相关系数 `> 0.97`。

质量随转弯幅度不严格单调，因此不得使用单一横向偏移阈值替代图像质量验收。

## 3. 空间变化残余矩阵

在 `12 m` 横向偏移场景中，以中心距离单元为一阶补偿参考点：

| 目标距离单元 | 最大残余斜距误差 |
|---:|---:|
| `20` | `0.000000 m` |
| `18` | `0.000594 m` |
| `16` | `0.001558 m` |
| `12` | `0.007119 m` |

残余随目标偏离参考点持续增大，证明单参考点补偿存在明确空间适用范围。

## 4. 工程决策

- 不批准通过简单阈值将 L3 接入 public RDA。
- 不直接实现二阶补偿；当前失效同时涉及非直线轨迹聚焦假设，不应只归因于残余相位。
- 进入 L3 专用 BP 研究，但 BP 必须与现有 GBP 共享后向投影数学核心，禁止复制两套易分叉实现。
- BP 与 GBP 的主要差异冻结为累加遍历顺序；相同输入应产生逐像素一致结果。

## 5. 验证结果

- 默认与 Eigen 3.3.9 L3/GBP/补偿/RDA/Session 过滤测试：各 `34/34 passed`。
- `ctest -L sar_ci`：`4/4 passed`。
- `ctest -L sar_performance`：`1/1 passed`。
- Eigen 3.3.9 `sar_cxx11_compat`：`1/1 passed`。
- `git diff --check`：passed。

## 6. 冻结边界

- 当前矩阵只覆盖 `9x9`、固定 PRF、单点目标和指定折线几何。
- 不推断到更大图像、更长孔径、时变 PRF 或真实平台动力学。
- public Session、BP public 入口、二阶补偿、自聚焦和 Auto 继续后置。
