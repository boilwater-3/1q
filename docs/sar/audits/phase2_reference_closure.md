# SAR Phase 2 参考级成像与算法对比闭环完成度审计

## 1. 审计结论

Phase 2“参考级成像与算法对比闭环”已完成当前固定 PRF、小场景、点目标范围内的工程闭环，但尚未形成足以支撑通用算法选择的代表性参考场景矩阵。

- RDA、GBP、BP、L2 一阶补偿和 L3 适用边界均有独立确定性证据。
- L3 BP 已完成受控 public Session 与摘要级 replay 接入。
- 当前证据可批准显式算法路径，不可批准 Auto、通用场景质量声明或扩大尺寸门。
- 下一扩展方向冻结为参考场景矩阵扩展，Auto 继续后置。

## 2. 已证明能力

| 审计项 | 当前证据 | 结论 |
|---|---|---|
| 统一质量指标 | 峰值、3dB 宽度、PSLR、ISLR、熵、相位对齐 NRMS、相关性 | 当前平台完成 |
| L1 RDA 基线 | 单点、同距离向三点、RDA/GBP 同场景对比 | 当前平台完成 |
| Sinc RCMC 对照 | 已知带限采样误差、相对 GBP 的质量与性能 | 当前平台完成，默认不切换 |
| GBP 参考路径 | L1/L3 逐脉冲实际位置、小场景质量与性能 | 当前平台完成 |
| BP 路径 | 与 GBP 共享核心，L1/L3 复图逐样本一致 | 当前平台完成 |
| L2 一阶补偿 | 零扰动严格退化、固定种子非零扰动改善 | 当前平台完成 |
| L3 适用边界 | `0-6 m` 当前门通过，`12 m` 明确失效 | 当前平台完成 |
| L3 BP Session | 固定 PRF waypoint、结构化拒绝、两周期 replay | 当前平台完成 |
| 尺寸与性能门 | RDA `1024x1024`，GBP/BP `128x128` | 当前平台完成 |

## 3. 尚未证明范围

| 缺口 | 风险 |
|---|---|
| 缺少方位偏置目标与二维多目标布局 | 当前跨算法结论主要来自中心单点和同距离向目标，不能代表二维场景 |
| 缺少靠近图像边界的可用质量矩阵 | 不能量化插值、主瓣截断和峰值定位边界 |
| 缺少硬件参数与采样参数扫描 | 不能宣称结论对载频、带宽、PRF、采样率普遍成立 |
| L3 public 仅固定 PRF，折线转角不具备动力学保真 | 不能宣称时变 PRF 或真实机动平台闭环 |
| GBP/BP 仍限制为 `128x128` | 不能作为大场景路径或 Auto 降级目标 |
| replay 仅保存摘要和 diagnostics | 不能通过 replay 独立审计全图复数样本 |
| 未冻结 Auto 选择阈值、降级规则和结构化选择诊断 | 即使算法各自通过，也不能批准自动切换 |

## 4. Auto 审计

RDA、GBP 和 BP 已分别具备回归与性能证据，但 Auto 仍不满足正式运行条件：

1. 当前参考矩阵不足以区分算法在二维目标布局、边界目标和多参数场景中的适用范围。
2. GBP/BP 受 `128x128` 门禁约束，且 GBP 未接入 public Session。
3. 尚未冻结选择规则、资源预算、拒绝/降级行为与 replay 诊断。
4. 用户已批准 Auto 继续后置。

因此本阶段不新增 selector，不以已有单点证据推导自动选择阈值。

## 5. 下一方向决策

下一阶段选择“参考场景矩阵扩展”，原因如下：

- 它直接补齐已批准主线的代表性证据缺口。
- 它可复用现有 RDA/GBP/BP、L2/L3 与质量指标，不需要提前增加 public API。
- 它能为未来 Auto、尺寸扩展、时变 PRF 或更高阶补偿提供可审计基线。

时变 PRF、全图 replay、二阶补偿、多参考点补偿和 Auto 均继续后置，等待矩阵证据完成后分别审批。

## 6. 审批边界

- 本审计只批准进入参考场景矩阵契约与实现。
- 不改变 RDA linear 默认路径。
- 不扩大 RDA `1024x1024` 或 GBP/BP `128x128` 上限。
- 不新增 public algorithm selector、runtime patch 或 focused complex image 输出。
