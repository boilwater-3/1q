# SAR L2/L3 联动价值评估报告(阶段 A)

Date: 2026-06-24
状态: **阶段 A 价值评估。判定:部分联动有价值(一致性矩阵),组合聚焦无需实现。**
评估范围:Phase 4 子项「L2/L3 联动」是否值得实现、实现什么、不实现什么。
依据:`l2_session_integration.md`、`l3_bp_session_integration.md`、`phase3_status_audit.md`、
`phase4_difficulty_assessment.md` §3.5 + 经代码逐行核查。

## 1. 评估目标

phase4 评估 §3.5 把「L2/L3 联动」列为 🟢 中低难度、最易先做。本报告回答三个问题:

1. **组合场景(L3 转弯 + L2 扰动)是否真有聚焦价值?** —— 即"L2×L3 组合聚焦"要不要做。
2. **多保真度一致性矩阵是否有价值?** —— 即"L1/L2/L3 同场景对比"要不要做。
3. **如果做,各自的工作量与收益比如何?** —— 据此给出 B 步契约的范围建议。

## 2. 核查事实(经代码逐行验证)

### 2.1 L2/L3 当前是物理互斥,非配置互斥

| 层 | 互斥机制 | 证据 |
|---|---|---|
| 配置校验 | `enable_l3_bp_imaging` 时拒绝 `enable_l1_rda_imaging` + `enable_l2_motion_compensation` | `SarRuntimeConfigValidation.cpp:71-79` |
| 轨迹生成 | `if (enable_l3_bp) {...} else if (enable_l2_moco) {...}` —— **if/else if 硬互斥** | `SarRawHistoryBuilder.cpp:118,144` |
| 聚焦执行 | L1-RDA(含 L2 补偿)与 L3-BP 是 `SarSession.cpp:162/169` 的两个独立 if 块 | `SarSession.cpp:162-174` |

关键:互斥**不是表面配置约束,是生成器层的物理互斥**。L3 分支与 L2 分支在同一 if/else-if 块,
无法同时触发。

### 2.2 L3 航路点轨迹无 ideal/actual 分离

L3 分支执行:`*ideal_pulses = *actual_pulses`(`SarRawHistoryBuilder.cpp:137`)。
航路点轨迹**本身就是"真实轨迹"**——它定义平台实际飞过的路径,不存在"理想 vs 实际"之分。

### 2.3 一阶运动补偿依赖 ideal/actual 双轨迹

`ApplyFirstOrderMotionCompensation` 签名强制要求 ideal + actual 双轨迹
(`SarMotionCompensation.h:33-37`),它修正的是"actual 偏离 ideal 的扰动相位"。

### 2.4 BP/GBP 逐脉冲精确投影,运动效应已内含(**决定性事实**)

`SarGbp.cpp:83`:`geometry::Distance(pulses[pulse].position_m, pixel)` ——
BP/GBP 对每个脉冲用**实际平台位置**精确计算到每个像素的斜距,直接消费 actual 轨迹。
**BP 是时域逐脉冲精确算法,平台运动的相位/包络效应已完全内含,不需要任何运动补偿。**

这是 L3 BP 路径**不接运动补偿**的根本原因——不是疏漏,是物理上不需要。

### 2.5 一阶补偿在转弯轨迹下失效(已证据冻结)

`l3_first_order_applicability_matrix.md` 实测:横向偏移 ≥ 12m 时一阶补偿失效
(NRMS 0.386),根因是 **RDA 平移不变聚焦假设崩溃**(非补偿精度不足)。
`second_order_motion_compensation.md` 阶段 A 进一步判定二阶补偿**不实现**——
零残余的参考点都散焦,二阶项修不了根因。**转弯应改用 BP(已就绪)。**

## 3. 联动方案收益比分析

### 3.1 方案 α:L2×L3 组合聚焦(L3 航路点 + L2 扰动叠加,经 BP 聚焦)

**语义**:actual = waypoint_track(宏观转弯)+ perturbation(微观抖动);ideal = waypoint_track。
BP 用 actual(含扰动)逐脉冲精确投影。

**收益**:**几乎为零**。理由(由 §2.4 决定性事实导出):
- BP 直接消费 actual 轨迹(`SarGbp.cpp:83`),actual 多少抖动,投影就用多少抖动。
- 联动只是把 actual 从"纯航路点"变成"航路点 + 扰动"——BP 照样精确处理,**无需任何新算法**。
- 一阶补偿对 BP **无意义**(BP 不需要补偿,§2.4);对 RDA 在转弯下**失效**(§2.5)。
- 即:L2 扰动叠加到 L3 轨迹上,BP 用扰动后的 actual 投影,结果天然正确——**这就是当前 BP
  已经在做的事**,只是现在 actual 只能是纯航路点。

**代价**:解 `SarRawHistoryBuilder.cpp` 的 if/else-if 互斥(改组合分支)、解 validation 互斥、
改 `*ideal_pulses = *actual_pulses`(让 L3 也保留 ideal)、配置语义("L3 + L2 扰动")、
replay/trace 保真。**中等改动,触及 session 核心轨迹生成。**

**收益比:🔴 低**。代价不小,收益是"让 BP 能吃一条带抖动的轨迹"——但 BP 吃任何轨迹都是精确的,
这个能力在算法上**没有新增价值**,只是配置层面的便利。

### 3.2 方案 β:多保真度一致性矩阵(L1/L2/L3 同场景跨算法系统化对比)

**语义**:同一物理场景(同一目标 + 同一几何),分别跑 L1-RDA / L2-RDA(补偿)/ L3-BP,
产出系统化的跨保真度对比证据矩阵(分辨率/峰值/相位一致性/散焦程度)。

**收益**:**高且独特**。理由:
- phase4 §3.5 明确这是"L2/L3 联动"缺的核心:"多保真度一致性矩阵(L1/L2/L3 同场景跨算法
  对比的系统化证据)"。
- 当前 L1/L2/L3 各自闭环(各有独立测试),但**跨保真度的系统化对比证据不存在**
  (grep `consistency_matrix|fidelity_matrix|联动|一致性矩阵` 在 tests/ 下**零命中**)。
- 这是"可审计性"的价值:证明同一场景在不同保真度下行为可解释、退化可控、边界清晰。
- 直接支撑二阶补偿冻结决策的正确性(矩阵展示 L2 一阶补偿在直线场景修复、L3 BP 在转弯场景修复,
  二阶补偿无必要)。

**代价**:**纯测试层**。L1/L2/L3 个体执行器全部就绪,只需在同场景下调用三个执行器 + 对比输出。
**零算法改动,零 session 改动,零配置改动。**

**收益比:🟢 高**。代价极低(纯测试),收益独特(系统化可审计证据)。

### 3.3 方案 γ:Session 层保真度选择编排(自动/半自动选择 L1/L2/L3)

**收益**:**低**。理由:
- `SarFocusingSelector` 已是"L1/L2/L3 × 3 目的纯咨询路由器"(`module_design.md:66,515`),
  但 session 刻意绕过它,用 policy 布尔位直接驱动。
- 自动选择的语义风险高(用户应显式选择保真度,非系统猜测),且当前布尔位已足够表达。
- phase4 §3.5 提及但未强调,且 selector 已"逻辑完整"。

**收益比:🟡 中低**。代价中(接 selector 到 session),收益是"自动化"——但保真度选择本就该显式。

## 4. 决策

| 方案 | 收益比 | 决策 |
|---|---|---|
| α L2×L3 组合聚焦 | 🔴 低(BP 已精确,联动无算法新增价值) | **不实现**(冻结) |
| β 多保真度一致性矩阵 | 🟢 高(纯测试,独特可审计价值) | **实现**(B 步契约范围) |
| γ Session 保真度编排 | 🟡 中低(selector 已完整,自动化风险高) | **不实现**(冻结) |

**B 步契约范围**:仅实现方案 β(一致性矩阵)。这是纯测试层工作:
- 不改任何 session/imaging/配置代码
- 不解 L2/L3 互斥(组合聚焦无价值,§3.1)
- 不接 SarFocusingSelector(保真度编排无价值,§3.3)
- 在 `tests/` 新增跨保真度一致性矩阵测试,系统化对比 L1-RDA / L2-RDA / L3-BP 在同场景下的输出

## 5. 关键洞察:为什么"组合聚焦"是伪需求

phase4 §3.5 把"L2×L3 组合场景"列为联动核心缺口。但经 §2.4 决定性事实核查,这个判断**忽略了
BP 的物理本质**:

- phase4 §3.5 假设"L3 转弯 + L2 扰动"需要新的聚焦编排。
- 实际上 BP(`SarGbp.cpp:83`)对任意 actual 轨迹都精确投影——actual 是纯航路点还是航路点+扰动,
  BP **同样精确处理**。
- 一阶补偿对 BP 无意义(BP 不补偿);对 RDA 在转弯下失效(§2.5)。
- 故"L2 扰动叠加到 L3"在 BP 路径下**不产生任何聚焦质量变化**——它只改变 actual 轨迹的抖动幅度,
  BP 照样精确投影。

**结论**:组合聚焦(方案 α)不实现。L2/L3 联动的真实价值在**可审计的一致性矩阵**(方案 β),
不在聚焦算法组合。

## 7. 与冻结边界的一致性

本评估不重开任何冻结项:
- 二阶运动补偿保持冻结(§2.5,组合聚焦不依赖它)。
- 不接 SarFocusingSelector(方案 γ 冻结)。
- 不解 L2/L3 互斥——组合聚焦(方案 α)冻结,互斥保持现状作为**正确的物理约束**(BP 不需补偿,
  L2 补偿对 RDA 有效但对 BP 无意义,故 L2/L3 互斥是设计正确,非遗漏)。
- 不扩大 BP 128×128 门。

## 8. 本评估的非目标

- 不起草聚焦算法改动(组合聚焦无价值)。
- 不修改任何源代码。
- 不重开二阶补偿/CSA/PGA/Auto 冻结。
- 不外推到 Phase 5(OpenMP/GPU/实时)。
- 不构成通用质量阈值授权。

## 9. 下一步(B 步契约建议)

若批准本评估的决策,则 B 步契约 `l2_l3_fidelity_matrix.md` 仅冻结:
1. 一致性矩阵的场景设计(同目标、同几何,L1/L2/L3 三路径)。
2. 对比指标(分辨率/峰值位置/相位一致性/散焦指标)。
3. 矩阵结构(保真度 × 算法 × 场景类型[直线/转弯]× 扰动档位)。
4. 验收门(矩阵全绿 + 个体路径零回归)。

**不冻结**任何 session/imaging/配置改动——一致性矩阵是只读消费者,复用全部现有执行器。
