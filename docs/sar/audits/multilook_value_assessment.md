# SAR 多视(Multilook)价值评估报告(阶段 A)

Date: 2026-06-24
状态: **阶段 A 价值评估。判定:有价值且独立,实现路径冻结为"聚焦后图像域非相干多视"。**
评估范围:Phase 4 子项「多视 Multilook」的必要性、实现路径选择、收益比。
依据:`phase4_difficulty_assessment.md` §3.2 + 经代码逐行核查。

## 1. 评估目标

phase4 评估 §3.2 把多视列为 🟠 中难度、独立、最易先做。本报告回答:

1. **多视是否有价值?** —— 降斑后处理在仿真库中是否有真实需求。
2. **多视应作用在哪一层?** —— 三种候选路径(聚焦后图像 / raw history / 距离-多普勒域)的收益比。
3. **多视是否真的独立?** —— phase4 声称独立,核查是否依赖其它子项。

## 2. 核查事实(经代码逐行验证)

### 2.1 多视完全零实现

- `grep -ril 'multilook|multi_look|number_of_looks|多视|n_looks'` 在 `src/`、`include/`、`tests/`
  下**零命中**(仅 `module_design.md` Phase 4 行提及)。
- 无视处理逻辑、无视数配置、无视叠加平均算子、无降斑滤波器(box/mean filter grep 零命中)。

### 2.2 聚焦图像输入已就绪(独立性确认)

多视的输入是聚焦复图像,当前有四种产出结构:

| 结构 | 来源 | 状态 |
|---|---|---|
| `FocusedSarImage`(L1-RDA) | `SarRda.h:61` | ✅ 已闭环 |
| `FocusedGbpImage`(GBP/BP) | `SarGbp.h:44` | ✅ 已闭环 |
| `FocusedOmegaKImage`(Omega-K) | `SarOmegaKFocusing.h:48` | ✅ 已闭环 |
| `FocusedScanSarImage`(ScanSAR) | `SarScanSarFocusing.h:69` | ✅ 已闭环 |

四种结构的图像体都是 `signal::ComplexMatrix`(`image` 字段),统一可消费。
**多视是它们的纯下游后处理,不依赖任何聚焦算法的内部细节——独立性确认。**

### 2.3 RDA 内部未暴露距离-多普勒域中间产物

`grep 'RangeDoppler|range_doppler|rd_domain|azimuth_freq'` 在 `SarRda.cpp` 下**零命中**。
RDA 聚焦是黑盒入口(`FocusStripmapRda`),内部 RD 域中间态不对外暴露。
Omega-K/GBP 同理——都是 raw → focused image 的黑盒。

> 这意味着"在距离-多普勒域分视"需要侵入聚焦算法内部,违背黑盒封装。

### 2.4 输出层有图像格式化器

`ImageFormatter`(`ImageFormatter.h`)提供 `WriteBinaryImage`/`WriteGeoTiffSidecar`/`WriteHdf5Image`,
消费 `session::SarFocusedImage`(含 `real_values`/`imaginary_values` 平面 vector)。
多视产物可作为新的 `SarFocusedImage` 经同一格式器输出,无需改输出层。

## 3. 实现路径收益比分析

多视的本质:把孔径(方位/距离)分成 N 个子孔径(视),各自独立聚焦后**非相干叠加**(取幅度/功率平均),
以 N 倍分辨率为代价换取 N 倍的相干斑抑制(斑噪声标准差降至 1/√N)。

### 3.1 路径 α:聚焦后图像域多视(分块平均)

**语义**:对已聚焦的复图像,在方位(和/或距离)向分成 N 个相邻子块(视),每块独立取幅度/功率,
再平均。等价于一个非相干空间平均滤波。

**收益**:**高**。理由:
- 输入就绪(四种聚焦结构都产出 `ComplexMatrix`)。
- 算法极简:分块 + 求幅度/功率 + 平均,O(N) 复杂度,无 FFT。
- 物理正确:聚焦后图像域的非相干平均是标准多视降斑方法,等效视数清晰。
- 独立于聚焦算法:对任何 `ComplexMatrix` 都适用(RDA/BP/OmegaK/ScanSAR 输出均可)。
- 零侵入:可作为 `imaging::` 自由函数,不改任何聚焦器/输出层。

**代价**:**极低**。一个自由函数 + 配置(视数)+ 测试。

**收益比:🟢 最高**。

### 3.2 路径 β:raw history 域多视(分孔径独立聚焦)

**语义**:把 raw history 的方位脉冲序列分成 N 段(每段一个视),各自独立跑完整聚焦(RDA/BP),
得到 N 幅子图像,再非相干叠加。

**收益**:**中,但与 α 等价且更贵**。理由:
- 物理上与 α 等价(聚焦是线性算子,分孔径聚焦后叠加 = 全孔径聚焦后分块叠加,对相干斑统计一致)。
- 但代价高 N 倍(N 次完整聚焦 vs 1 次聚焦 + 平均)。
- 仅在"每视需不同聚焦参数"时有差异——当前各聚焦器参数固定,无此需求。

**代价**:中(N 次聚焦调用 + 配置 + 子图像对齐)。

**收益比:🟡 中低**。物理等价 α 但更贵,无额外收益。

### 3.3 路径 γ:距离-多普勒域多视(分多普勒子带)

**语义**:在 RDA 的距离-多普勒域(RD 域),把多普勒频谱分成 N 个子带(视),各子带独立方位压缩,
得到 N 视,非相干叠加。这是**理论上最优**的多视(各视统计独立性好)。

**收益**:**理论最优但工程不可行**。理由:
- 需侵入 RDA 内部(`SarRda.cpp` 不暴露 RD 域,§2.3),破坏黑盒封装。
- 仅对 RDA 适用(BP/OmegaK 无 RD 域概念),不通用。
- 与聚焦算法强耦合,违背"多视是独立后处理"的设计原则。

**代价**:高(侵入 RDA + RD 域分视 + 方位压缩分视 + 重组)。

**收益比:🔴 低**。理论略优但工程代价高、不通用、破坏封装。

## 4. 决策

| 路径 | 收益比 | 决策 |
|---|---|---|
| α 聚焦后图像域多视 | 🟢 最高 | **实现**(B 步契约范围) |
| β raw history 域多视 | 🟡 中低(与 α 等价但更贵) | **不实现**(冻结) |
| γ 距离-多普勒域多视 | 🔴 低(侵入 RDA,不通用) | **不实现**(冻结) |

**B 步契约范围**:仅实现路径 α(聚焦后图像域非相干多视)。
- 作用对象:任意聚焦复图像(`signal::ComplexMatrix`)。
- 算法:方位/距离向分块(视),每视取幅度(或功率),平均降斑。
- 形态:`imaging::` 自由函数,输入聚焦图像 + 视数配置,输出多视后图像。
- 零侵入:不改任何聚焦器、输出层、session、配置结构(多视是独立后处理工具)。

## 5. 关键洞察:为什么聚焦后图像域是最优路径

phase4 §3.2 列了多视的难点之一是"是否在距离-多普勒域分视"。经 §2.3 核查:

- RD 域多视(路径 γ)理论略优(各视多普勒子带统计独立性好),但:
  - RDA 不暴露 RD 域(`SarRda.cpp` 黑盒),需侵入内部。
  - 仅对 RDA 适用,BP/OmegaK/ScanSAR 无 RD 域——不通用。
  - 聚焦后图像域多视(路径 α)的相干斑抑制效果在工程上**足够**(对均匀场景,等效视数 ≈ 分块数)。

- 仿真库的多视需求是"展示降斑效果 + 提供降斑后处理能力",不是追求极致统计独立性。
  路径 α 的简单空间平均已满足此需求,且对四种聚焦器通用。

**结论**:聚焦后图像域多视(路径 α)是收益比最优的路径——输入就绪、算法极简、通用、零侵入。

## 6. 收益比量化对比

| 维度 | 路径 α(图像域) | 路径 β(raw 域) | 路径 γ(RD 域) |
|---|---|---|---|
| 算法改动 | 1 自由函数(分块+平均) | N 次聚焦 + 对齐 | 侵入 RDA + 分视 |
| 聚焦器改动 | 0 | 0 | RDA 需暴露 RD 域 |
| 通用性 | 全部 4 种聚焦器 | 全部(但 N× 代价) | 仅 RDA |
| 物理正确性 | ✅ 标准降斑 | ✅ 与 α 等价 | ✅ 理论最优 |
| 复杂度 | O(N) 无 FFT | O(N) × 聚焦 | 高(RD 域手术) |
| 人天估计 | **3-5** | 5-7 | 8-12 |
| 收益/代价比 | **最高** | 中 | 低 |

## 7. 与冻结边界和独立性的关系

### 7.1 独立性确认

phase4 §3.2 声称多视独立。经核查确认:
- 输入(聚焦图像)就绪(§2.2,四种结构全闭环)。
- 不依赖聚束/扫描/L2L3/GeoTIFF 任何子项。
- 不依赖任何冻结项(CSA/PGA/二阶补偿/Auto)。
- **可与任何已实现的聚焦器组合**(RDA/BP/OmegaK/ScanSAR 输出均可多视)。

### 7.2 冻结边界保持

- 不重开 CSA/PGA/二阶补偿冻结。
- 不侵入任何聚焦器内部(路径 γ 冻结)。
- 不改输出层(ImageFormatter)——多视产物是新的 `ComplexMatrix`,可经现有格式器输出。
- 不改 session/配置(多视是独立后处理工具,不进 session 数据链路——与聚束/扫描一致,
  这些模式也未接 public Session,走自由函数)。

## 8. 本评估的非目标

- 不实现 RD 域多视(路径 γ,侵入 RDA 不通用)。
- 不实现 raw 域多视(路径 β,与图像域等价但更贵)。
- 不修改任何源代码。
- 不重开任何冻结项。
- 不外推到 Phase 5(OpenMP/GPU/实时多视)。

## 9. 下一步(B 步契约建议)

若批准本评估的决策,则 B 步契约 `multilook_processing.md` 冻结:
1. **算法**:聚焦后图像域非相干多视——方位/距离向分块,每视取幅度/功率,平均。
2. **配置**:视数(`azimuth_looks`/`range_looks`)、平均类型(幅度/功率)、边界处理。
3. **接口**:`imaging::ApplyMultilook` 自由函数,输入 `ComplexMatrix` + 配置,输出 `ComplexMatrix`。
4. **不变量**:单视(looks=1)退化为输入不变;视数越大分辨率越低、降斑越强。
5. **验收门**:降斑效果量化(多视后方差/对比度变化)+ 退化不变 + 全量回归 + sar_ci/sar_performance 门。
6. **非目标**:不进 session、不改聚焦器、不做 RD 域/raw 域多视。
