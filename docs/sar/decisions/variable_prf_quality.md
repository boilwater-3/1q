# SAR 时变 PRF 质量矩阵后续决策

## 1. 决策结论

当前质量矩阵不足以批准 RDA 前置处理接入。二维重采样与质量矩阵保持内部参考能力。
下一阶段选择缺失脉冲与最大慢时间间隙诊断契约。

## 2. 证据边界

固定单点场景中，抖动比例增大时 raw-history 与图像 NRMS 稳定增大，`A=0.35` 仍保持
较小误差。但该结论没有覆盖：

- 缺失脉冲和大时间间隙。
- 多目标、高 Doppler 和边缘目标。
- 随机/突发抖动。
- public 请求语义与失败传播。

## 3. 接入决策

- 不接入 RDA 默认路径、Session、public API、schema、trace 或 replay。
- 不冻结通用抖动通过阈值。
- 不自动修复缺失脉冲。

## 4. 下一方向

下一阶段先以名义间隔为基准冻结最大间隙比、疑似缺失脉冲计数和拒绝语义。该诊断只
决定是否允许进入重采样，不负责插值修复或生产成像。
