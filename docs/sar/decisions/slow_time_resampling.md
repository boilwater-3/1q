# SAR 时变 PRF 慢时间重采样后续接入决策

## 1. 决策结论

复数向量慢时间重采样保持为内部基础能力，暂不接入 RDA 或 Session。下一阶段选择二维
raw-history 慢时间重采样契约，用相同时间映射逐距离列处理，并继续保持生产成像后置。

## 2. 接入前置缺口

- 尚无带限 SAR 回波的线性插值误差阈值。
- 尚无缺失脉冲识别、最大间隙门和修复策略。
- 尚无重采样前后 RDA/GBP 独立质量矩阵。
- public 输入没有已审批的显式时变 PRF 请求语义。

因此不能把当前向量基础直接接入 RDA、Session、schema、trace 或 replay。

## 3. 可继续范围

二维 raw-history 重采样可以复用同一显式时间轴，对每个距离列独立应用相同插值权重。
该能力可先验证：

- 矩阵尺寸和 row=方位、col=距离约定。
- 各距离列互不串扰。
- 每列复数仿射解析真值。
- 均匀输入严格退化。

首批不执行 RDA，不声明带限回波质量达标。
