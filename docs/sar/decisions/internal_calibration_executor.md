# SAR 内部校准执行器后续接入决策

## 1. 决策结论

阶段 65 不批准将内部校准执行器直接接入 `SarSession`。执行器保持独立内部能力，直到
出现可审计的显式请求来源。public 摘要、schema、runtime patch 和 replay 继续后置。

下一方向转入 `1.1.4.4 SAR雷达组件`剩余能力审计，优先评估 Phase 3 聚焦算法
CSA/Omega-K 的工程准备度与实现顺序。

## 2. 接入审计

- 执行器、显式观测和定标核心均已通过内部闭环。
- `SarSession` 当前没有内部或 public 显式校准请求来源。
- 自动从普通目标列表生成请求违反显式标定器身份契约。
- 固定内置请求只适用于测试场景，不能成为生产 Session 行为。
- 在没有请求来源时接入只会产生永远无输出的死分支。

## 3. 保留结论

- 内部执行器继续作为算法与未来接入参考实现。
- 不增加 public calibration policy、cycle input、output diagnostics 或 replay 字段。
- 不增加自动目标/像素选择、有效性阈值或跨周期缓存。
- 完整系统因子继续等待发射功率、增益、损耗和处理增益统一语义。

## 4. 下一方向

辐射定标内部能力已达到当前可审计边界。下一步回到长期建设方案剩余项目，先审计
CSA、Omega-K、Auto、自聚焦、时变 PRF 和图像产品输出的依赖与风险，再选择下一实现线。
