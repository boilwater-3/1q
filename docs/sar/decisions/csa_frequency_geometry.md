# SAR CSA 频率几何后续决策

## 1. 决策结论

CSA 频率几何基础保持为独立内部诊断能力。完整 CSA 相位函数、聚焦入口和内部选择器
接入继续后置。下一条 SAR 雷达组件建设线选择 Omega-K 数学与参考真值工程契约。

## 2. 证据审计

仓库当前具备：

- 未 shift 二维频率轴约定。
- `D(f_a)`、`alpha(f_a)` 和有效域诊断。
- RDA、GBP、BP 的现有参考与质量证据。

仓库当前不具备：

- 经审计的完整 chirp-scaling、SRC/RCMC 和方位压缩相位函数。
- 固定复数中间域结果或逐项固定相位样本。
- 可重复运行的独立 CSA 参考脚本。
- 完整 CSA 与独立参考之间的中间域误差阈值。

因此，现有证据只能批准几何基础，不能通过最终峰值对比反推完整相位函数正确。

## 3. 接入决策

- 不新增完整 CSA 聚焦入口。
- 不把 CSA 加入内部聚焦选择器的可用算法集合。
- 不新增 public 枚举执行路径、Session、schema、trace、replay 或 runtime patch。
- 不修改 RDA 默认路径。

## 4. 下一方向

Omega-K 同样缺少完整公式和独立真值，但其二维频谱、传播色散关系、有效域与 Stolt
映射前置条件可以先形成工程契约。下一阶段只冻结可验证的数学边界和独立真值要求，
不直接实现完整 Omega-K。
