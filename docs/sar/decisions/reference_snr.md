# SAR SNR 鲁棒性矩阵后续决策报告

## 1. 决策问题

判断首批 SNR 矩阵是否需要继续增加档位或 seed，以及 clean/noisy 比较是否具备统一口径。

## 2. 输出支持范围修正

初始矩阵中：

- RDA clean/noisy 比较使用完整 RDA 输出。
- GBP clean/noisy 比较使用小场景输出。

两者支持范围不同，绝对 NRMS 不可横向比较。后续矩阵已将 RDA clean/noisy 比较裁剪到与 GBP 相同的 `9x9` 窗口。

统一窗口后，seed `17` 的 M1 RDA clean/noisy NRMS 为：

`30/20/10/0 dB -> 0.006040/0.019105/0.060421/0.189517`

对应 GBP 为：

`0.000907/0.002871/0.009089/0.028854`

M4 保持相同趋势。两种算法对相同 raw 噪声的传播不同，但现有证据仍不足以定义优劣或通用阈值。

## 3. 决策

- 统一使用与 GBP 相同的小场景窗口进行 RDA clean/noisy 参考比较。
- 当前双 seed 与 `30/20/10/0 dB` 档位足以建立首批趋势，不立即增加矩阵规模。
- 不批准 SNR 质量阈值、质量警告、结构化拒绝或 Auto。
- 下一参考级缺口选择测试侧确定性分布式杂波模型；生产杂波、公用配置和绝对功率语义继续后置。
