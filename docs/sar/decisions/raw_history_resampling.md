# SAR 二维慢时间重采样后续接入决策

## 1. 决策结论

二维 raw-history 重采样暂不接入 RDA、Session 或 public 表面。下一阶段建立时变 PRF
重采样质量参考矩阵，使用固定参考场景量化 raw-history 与聚焦图像误差，并识别通过区
与失效区。

## 2. 当前具备证据

- 固定参考点场景与确定性 raw-history 构建。
- 二维 raw-history 慢时间重采样基础。
- RDA、GBP 和跨图像 NRMS/相干相关指标。

## 3. 当前缺口

- 没有抖动幅度与 raw-history 插值误差的参数矩阵。
- 没有重采样后 RDA 相对均匀基线的质量趋势。
- 没有最大时间间隙、缺失脉冲和拒绝阈值。

因此当前不批准 RDA 前置处理接入。下一阶段只冻结质量矩阵和趋势门，仍不修改生产路径。
