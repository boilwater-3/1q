# SAR Omega-K 显式网格收缩后续决策

日期：2026-06-11

## 1. 决策

显式网格收缩执行器保持内部频率域能力。收缩窗口来自原始均匀距离频率网格的连续
子集，因此可继续冻结 inverse-range FFT 的相对延迟采样轴；但绝对斜距原点、参考
相位、二维 IFFT 与完整 Omega-K 聚焦继续后置。

## 2. 依据

- 收缩目标频率轴严格递增、间隔保持均匀，并显式保留原始列索引。
- 频率样本数和间隔足以定义周期性离散 inverse FFT 相对延迟轴。
- 频率窗口不再包含原完整带宽，距离分辨率、无模糊延迟范围和幅度尺度会变化。
- 没有参考相位与斜距原点时，不能把相对延迟轴解释为绝对地理距离轴。

## 3. 下一方向

冻结收缩距离频率网格的均匀性诊断、inverse-range FFT 相对延迟轴、分辨率与无模糊
窗口口径。首批只验证数值轴和 FFT 往返，不生成完整 Omega-K 图像。
