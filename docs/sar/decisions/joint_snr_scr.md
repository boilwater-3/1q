# SAR 联合 SNR/SCR 矩阵后续决策

## 1. 决策结论

阶段 56 完成联合 SNR/SCR 首批矩阵审计。本轮不继续扩展中间档位、不启动相关杂波，
也不建立联合输入质量阈值或生产 diagnostics。

下一方向选择 `1.1.4.4.3.4 辐射定标模块`，先冻结测试侧辐射定标与绝对 RCS 反演
工程契约，再决定是否进入生产接口。

## 2. 证据审计

- M1 已覆盖 clean、noise-only、clutter-only 与 joint 的 `3x3` 完整组合。
- M4 已覆盖 clean、`20 dB + 20 dB` 与 `0 dB + 0 dB` 多目标哨兵组合。
- 两组独立 seed 对均保持分量隔离、能量定义和 BP/GBP 一致性。
- 当前矩阵足以证明确定性与总体退化趋势，但不足以形成通用质量有效性阈值。

## 3. 候选方向判断

### 更多中间 SNR/SCR 档位

暂缓。增加 `10 dB` 等档位会提高趋势分辨率，但不会改变当前“不得冻结通用阈值”的
结论，工程收益有限。

### 相关杂波与随机位置

暂缓。进入实现前必须先冻结位置分布、空间相关函数、相关长度、功率归一化和独立参考
结果；当前没有足够证据选择这些参数。

### 联合输入质量诊断

暂缓。当前只能记录 requested/realized SNR/SCR，尚无证据将其映射为算法有效性警告、
结构化拒绝或 Auto 选择条件。

### 辐射定标闭环

选择。长期方案明确列出 `1.1.4.4.3.4 辐射定标模块`；现有目标 RCS、raw history、
聚焦图像、确定性噪声和杂波能力已经具备冻结测试侧定标语义的基础。

## 4. 下一阶段边界

- 先冻结标定目标、定标常数、绝对 RCS 反演和多点融合口径。
- 首批只做测试侧/内部算法闭环，不直接修改 public API、Session 或 replay。
- 不宣称真实系统绝对功率精度，不引入天线方向图、系统损耗或实测标定数据。
- 生产噪声、生产杂波、相关杂波、质量阈值和 Auto 继续后置。
