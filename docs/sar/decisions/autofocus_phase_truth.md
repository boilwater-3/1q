# SAR 自聚焦相位真值后续决策

## 1. 决策结论

自聚焦相位误差真值保持为独立内部诊断能力。PGA、生产图像校正和 Session 接入继续
后置。下一条 SAR 雷达组件建设线选择时变 PRF 慢时间采样与重采样工程契约。

## 2. 证据审计

当前已具备低阶注入剖面、不可观测分量去除和校正真值，但仍缺少强散射点支持区、
相位梯度固定估计结果、unwrap 规则、迭代停止准则和独立图像域参考。因此不能仅依据
熵下降实现或批准 PGA。

## 3. 接入决策

- 不实现 PGA 或生产图像校正。
- 不接入内部聚焦选择器、Session、public API、schema、trace 或 replay。
- 不修改 RDA 默认路径。

## 4. 下一方向

几何层已有显式脉冲时刻，但当前 RDA/CSA/Omega-K 频率轴仍假设均匀 PRF。下一阶段先
冻结时变 PRF 慢时间采样、非均匀度诊断与重采样真值边界，不直接批准非均匀成像。
