# SAR Omega-K 复数 Stolt 插值后续决策

日期：2026-06-11

## 1. 决策

复数 Stolt 线性插值保持内部独立能力，不进入完整 Omega-K 聚焦。完整未 shift 目标
距离频率网格在非零 Doppler 行产生越支持区查询，当前插值器按契约原子拒绝。

下一阶段冻结全方位 Doppler 行共同有效的目标距离频率支持窗口诊断。

## 2. 证据

- 支持区内仿射复数谱可被线性插值精确恢复。
- 未 shift 源轴通过频率排序视图正确处理，输出列顺序保持不变。
- 零 shift 严格退化，越支持区查询原子拒绝。
- `SarOmegaKGeometry` 的完整目标网格包含越支持区查询，证明完整执行链仍缺少网格策略。

## 3. 禁止项

- 不自动填零、裁剪、外推或周期回绕越支持区查询。
- 不隐式改变输出列数、距离频率间隔或相位参考。
- 不新增完整 Omega-K 聚焦、选择器、Session、public API 或 replay。

## 4. 下一方向

计算每个目标距离频率列在全部方位 Doppler 行上的 Stolt 查询有效性，形成共同有效列
掩码、最大连续窗口、丢弃列数和有效比例诊断。诊断只提供决策证据，不自动执行网格
收缩或插值。
