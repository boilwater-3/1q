# SAR 显式标定观测后续决策

## 1. 决策结论

阶段 62 选择“内部显式校准请求与 Session 执行边界”作为下一方向。暂不实现自动像素
定位、主瓣积分功率，也不接入 public API、Session schema 或 replay。

## 2. 当前已具备能力

- 内部聚焦链路可产生未归一化 RDA/GBP/BP 复图像。
- 显式观测对象可以从调用方指定像素提取功率。
- 内部定标核心可以完成多点融合、RCS 反演和误差评估。
- 显式观测会保留身份、斜距、像素和孔径审计信息。

## 3. 候选方向判断

### Session 内部受控接入

选择，但必须先冻结内部显式请求。请求必须由调用方提供标定器身份、目标索引或位置、
预期图像像素和已知 RCS；Session 不得自动从普通目标列表选择。

### 自动像素定位

暂缓。全局峰值会在多目标场景中选择错误目标；局部搜索窗口、亚像素插值和目标重叠
需要独立契约与误差矩阵。

### 主瓣积分功率

暂缓。必须冻结主瓣边界、重叠目标处理和不同算法响应支持范围；当前峰值功率闭环已足以
推进显式接入。

### public diagnostics / replay

暂缓。在内部请求、执行时机、失败语义和结果生命周期验证前，不扩大公共表面。

## 4. 下一阶段边界

- 冻结内部请求对象和显式启用语义。
- 请求必须绑定一个确定性标定目标与指定像素。
- 冻结请求与 L1 RDA、L2 补偿 RDA、L3 BP 的支持边界。
- 冻结成功、拒绝和无输出行为，不静默回退。
- 首批不修改 public config、cycle input/output、schema、runtime patch 或 replay。
