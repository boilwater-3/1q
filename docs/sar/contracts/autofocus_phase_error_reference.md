# SAR 自聚焦残余相位误差与参考真值工程契约

## 1. 目标

为 SAR 自聚焦建立可控、可审计的残余相位误差真值。首批只批准低阶相位误差剖面、
不可观测常量/线性分量去除和校正真值诊断，不直接批准 PGA 估计器、图像熵优化或
Session 自动自聚焦。

## 2. 首批输入边界

- L1 broadside 小场景。
- 均匀方位采样，至少 3 个方位样本。
- 使用有限的低阶多项式相位误差系数。
- 输入为内部测试/诊断请求，不来自 public runtime patch。
- 不支持时变 PRF、斜视、聚束、L2/L3、噪声自适应或多目标选择。

## 3. 归一化孔径坐标

对方位样本 `n=0..N-1`：

$$
x_n = \frac{2n}{N-1}-1
$$

因此首尾样本分别为 `-1` 和 `1`。

## 4. 首批相位误差真值

低阶相位误差：

$$
\phi(x) = a_0 + a_1 x + a_2 x^2 + a_3 x^3
$$

所有系数单位为 rad。首批不批准更高阶、分段、随机或数据驱动误差模型。

## 5. 不可观测分量

自聚焦相位误差中的常量项只改变全局相位，线性项只改变方位位置。首批将二者定义为
不可观测分量。对离散 `phi[n]` 以最小二乘拟合：

$$
\phi_{unobservable}(x)=b_0+b_1x
$$

可观测残余：

$$
\phi_{observable}[n]=\phi[n]-(b_0+b_1x_n)
$$

真值校正剖面：

$$
\phi_{correction}[n]=-\phi_{observable}[n]
$$

纯常量或纯线性误差的可观测残余必须为零，不得被宣称为自聚焦可恢复内容。

## 6. 首批诊断

至少记录：

- sample count
- 输入 `a0..a3`
- 拟合不可观测 `b0/b1`
- observable residual RMS / maximum absolute phase
- correction RMS / maximum absolute phase
- removal residual mean and linear projection
- finite / valid status

## 7. 首批验收矩阵

1. 归一化坐标覆盖 `[-1,1]`，中心奇数样本为零。
2. 纯常量与纯线性误差去除后可观测残余为零。
3. 二次与三次误差保留可观测分量，校正剖面与其严格相反。
4. 原始相位等于不可观测分量与可观测残余之和。
5. 残余均值与对 `x` 的线性投影接近零。
6. 非有限系数和不足样本被拒绝，输出不包含 NaN/Inf。
7. 重复计算确定，默认与 Eigen 3.3.9 C++11 门通过。

## 8. 尚未批准内容

- PGA 相位梯度估计、积分、unwrap 和迭代停止准则。
- 强散射点选择、range-bin 筛选和窗口策略。
- 图像熵或对比度优化。
- 将校正剖面应用于生产图像或 Session。
- public API、schema、trace、replay、Auto 与失败回退。

## 9. 独立参考真值计划

PGA 实现前必须使用本契约的显式注入剖面建立固定相位历史和估计误差阈值，并验证去除
常量/线性分量后的恢复误差。只比较图像熵下降不足以批准估计正确性。

## 10. 实现边界

- 下一阶段只实现相位误差剖面、不可观测分量拟合和校正真值诊断。
- 不修改复数图像，不实现 PGA 或通用自聚焦。
- 不接入内部聚焦选择器、Session 或 public 表面。
