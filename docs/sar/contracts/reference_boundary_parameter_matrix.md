# SAR 图像边界与采样/硬件参数适用性矩阵工程契约

## 1. 目标

在首批 M1-M7 二维参考场景矩阵基础上，量化目标接近距离/方位边界以及采样与硬件参数变化时的成像质量和失效边界。

本阶段只建设内部确定性矩阵与审批证据，不改变 public API、默认算法、尺寸门或 Auto 状态。

## 2. 边界分类契约

每个边界场景必须分类为：

- `interior_pass`：目标主瓣未被图像或 raw history 边界截断，并通过已审批质量门。
- `boundary_degraded`：仍可成像，但峰值、主瓣、NRMS、相关性或旁瓣指标显示明确退化。
- `echo_clipped`：raw echo 已报告裁剪，不能作为完整成像质量通过证据。
- `invalid`：输入不满足算法契约并被明确拒绝。

禁止将 `echo_clipped` 或 `boundary_degraded` 场景通过扩大比较窗口、放宽阈值或忽略裁剪诊断归类为通过。

## 3. 首批边界矩阵

| 编号 | 场景 | 主要证据 |
|---|---|---|
| B1 | 距离中心单点 | 保持 M1 基线 |
| B2 | 距离下侧内部偏置与近边界目标 | 峰值、裁剪、NRMS、相关性 |
| B3 | 距离上侧内部偏置与近边界目标 | 峰值、裁剪、NRMS、相关性 |
| B4 | 方位中心、内部偏置与网格边缘目标 | 峰值、主瓣截断、NRMS、相关性 |

距离边界必须同时检查 raw echo clipping diagnostics；方位边界必须记录 3dB 主瓣宽度、PSLR、ISLR 和图像熵。

## 4. 首批参数矩阵

保持点目标、算法和输出网格定义一致，分别扫描：

| 编号 | 参数 | 首批档位 |
|---|---|---|
| P1 | `sample_rate_hz` | `80 / 100 / 120 MHz` |
| P2 | `carrier_frequency_hz` | `0.8 / 1.0 / 1.2 GHz` |
| P3 | `prf_hz` | `10 / 20 / 40 Hz` |
| P4 | `platform_velocity_mps` | `1 / 2 / 4 m/s` |

每次只改变一个参数，其他参数保持基线。若某档不满足采样或算法前提，必须记录为适用边界，不得静默替换配置。

## 5. 比较与记录

每个可执行场景必须记录：

- raw echo 是否裁剪及裁剪脉冲/样本证据。
- RDA、GBP、BP 实际执行路径。
- 峰值位置、距离/方位 3dB 宽度、PSLR、ISLR、图像熵。
- RDA 相对 GBP 的全局常数相位、单位能量形状 NRMS 和相干相关系数。
- BP 与 GBP 是否逐样本一致。
- 场景分类与分类原因。

## 6. 验收门

- B1 保持 M1 已审批基线。
- 内部偏置目标必须落在预期像素邻域，并明确区分完整回波和裁剪回波。
- 方位网格边缘若出现主瓣截断，必须记录为退化边界，不以峰值仍存在宣称通过。
- 参数矩阵必须确定性重复；同一配置重复输出一致。
- 对通过档位应用既有 L1 RDA/GBP 门：NRMS `<0.1`、相关系数 `>0.99`。
- 对未通过档位保留真实失败并冻结适用范围，不放宽既有门。
- 默认与 Conan Eigen 3.3.9 SAR 回归、`sar_ci`、`sar_performance` 和 C++11 兼容门继续通过。

## 7. 冻结边界

- 不启用 Auto，不生成算法选择阈值或降级规则。
- 不扩大 RDA `1024x1024` 或 GBP/BP `128x128` 尺寸门。
- 不实现时变 PRF 调度、真实动力学 L3、二阶补偿、多参考点补偿、自聚焦、并行/GPU 或全图复矩阵 replay。
- 不新增 public 配置或输出字段。

## 8. 后续审批

边界与参数矩阵完成后，再根据真实失效分布选择：

1. 扩大参数与场景覆盖。
2. 修复明确的算法边界缺陷。
3. 审批时变 PRF 或更真实 L3。
4. 重新审计 Auto。
