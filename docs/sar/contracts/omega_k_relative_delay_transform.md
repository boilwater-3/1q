# SAR Omega-K 收缩频谱相对延迟变换执行器契约

## 1. 目标

将已审批的收缩距离频率轴诊断与 inverse-range FFT 组合为内部显式执行器。成功时
返回相对延迟轴和距离时域复数矩阵；不执行方位 IFFT 或完整聚焦。

## 2. 请求

- 非零 request id；
- 严格递增、均匀的收缩目标距离频率轴；
- 行数为方位频率 bin、列数等于频率轴长度的复数频谱。

## 3. 执行

1. 验证 request id、频率轴和复数矩阵结构。
2. 计算收缩频率轴与相对延迟轴诊断。
3. 对频谱逐行执行 inverse FFT。
4. 原子返回相对延迟轴、诊断与距离时域矩阵。

## 4. 输出与拒绝

成功输出保持输入行数，列数等于相对延迟轴长度。拒绝时矩阵和延迟轴均为空。

结构化拒绝原因至少包括：无效 request id、无效频率轴、无效频谱和 inverse FFT 失败。

## 5. 验收

1. 单 bin、冲激和非对称复数频谱与 FFT facade 真值一致。
2. inverse 后逐行 forward FFT 恢复输入频谱。
3. 非均匀轴、形状错误和非有限样本明确拒绝。
4. 输入不变，相同请求重复执行确定。
5. 默认与 Eigen 3.3.9 环境测试及 C++11 门通过。

## 6. 后置内容

- 绝对斜距原点、负延迟中心化、参考相位和方位 IFFT。
- 完整 Omega-K 图像、质量矩阵、选择器和生产接入。
