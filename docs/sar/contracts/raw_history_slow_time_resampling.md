# SAR 二维 raw-history 慢时间重采样契约

## 1. 目标与边界

将已审批的复数向量慢时间线性重采样扩展到内部二维 raw-history。首批只批准逐距离列
应用同一慢时间映射，不接入 RDA、Session 或 public 表面。

## 2. 矩阵约定

- 使用现有 `signal::ComplexMatrix`。
- `rows = azimuth pulse count`，`cols = range sample count`。
- `values.size() == rows * cols`，rows 至少为 2，cols 至少为 1。
- 显式脉冲时刻数量必须等于 rows。

## 3. 重采样规则

- 名义均匀时间轴和诊断严格复用 `SAR_VARIABLE_PRF_RESAMPLING_CONTRACT.md`。
- 所有距离列共享同一组查询时刻、区间索引和线性权重。
- 每列只沿 row 方向重采样，禁止跨列混合。
- 输出矩阵尺寸与输入严格一致。
- 首尾方位行严格复用输入首尾行。

## 4. 独立参考真值

每个距离列使用不同系数的复数仿射慢时间信号。重采样后每列必须恢复各自解析真值，
且修改单一输入列不得影响其他输出列。

## 5. 首批验收矩阵

1. 均匀输入矩阵逐样本严格退化。
2. 非均匀多列仿射信号恢复解析真值。
3. 首尾行和矩阵尺寸保持。
4. 单列修改不影响其他列。
5. 非法矩阵尺寸、时刻数量和非有限样本被拒绝。
6. 输入不变、重复计算确定，双环境 C++11 门通过。

## 6. 尚未批准内容

- 带限 SAR 回波质量阈值、缺失脉冲策略和大间隙插值。
- RDA/CSA/Omega-K 接入、生产成像或自动选择。
- Session、public API、schema、trace 和 replay。

## 7. 下一实现边界

下一阶段只实现内部二维矩阵线性重采样与诊断复用，不修改现有聚焦路径。
