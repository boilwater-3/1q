# SAR 显式标定观测工程契约

## 1. 目标

在不修改 public API、Session schema 和 replay 的前提下，为内部辐射定标核心建立显式、
可审计的标定观测对象。观测对象负责说明“哪个目标、哪个像素、哪份未归一化图像、
哪个斜距和哪个时间窗口”被用于定标。

本阶段只冻结内部观测语义和首批验收边界，不自动从普通目标列表选择标定器。

## 2. 显式观测对象

每份标定观测至少包含：

- `observation_id`：调用方提供的非空稳定标识。
- `known_rcs_m2 > 0`：标定目标已知 RCS。
- `slant_range_m > 0`：观测参考时刻的目标斜距。
- `image_row` / `image_col`：明确指定的聚焦图像像素。
- `image_power > 0`：该像素的未归一化复图像功率。
- `aperture_start_pulse_id` / `aperture_end_pulse_id`：观测使用的孔径范围。
- `weight > 0`：多点融合的显式权重。

观测构建必须由调用方显式提供目标身份和预期像素。内部模块不得扫描普通目标列表并
猜测标定器，也不得自动使用整幅图像的全局峰值作为标定目标。

## 3. 图像功率提取

首批只批准指定像素的峰值功率：

$$
P_{pixel} = |I[row][col]|^2
$$

输入图像必须：

- 为未归一化复聚焦图像。
- 具有非零 rows/cols，存储尺寸与维度一致。
- 指定像素在边界内。
- 指定像素功率有限且大于零。

首批不批准主瓣积分功率、自动峰值搜索、亚像素插值或多目标解混。

## 4. 斜距与时间口径

- `slant_range_m` 由调用方基于标定目标位置和明确的观测参考时刻提供。
- 首批参考时刻为合成孔径中心脉冲。
- `aperture_start_pulse_id <= aperture_end_pulse_id`，二者用于审计观测来源。
- 观测构建模块不从图像像素反推斜距，也不修改调用方提供的斜距。

## 5. 观测生命周期

- 每份观测是不可变值对象，不持有图像指针。
- 定标模块只消费本次显式传入的观测列表，不维护隐式全局缓存。
- 新观测不会自动替换旧定标结果；调用方必须显式重新执行定标并替换结果。
- 任一观测无效时，整次多点定标失败，不允许静默跳过。
- 首批不定义跨 Session 持久化、过期时间、runtime patch 或 replay。

## 6. 转换为定标样本

有效观测一一转换为阶段 58 的 `CalibrationSample`：

$$
known\_rcs = observation.known\_rcs
$$

$$
image\_power = |I[row][col]|^2
$$

$$
slant\_range = observation.slant\_range
$$

$$
weight = observation.weight
$$

观测构建和定标计算保持分离，便于独立验证来源与数学闭环。

## 7. 首批验收矩阵

1. 从 M1 GBP 与 BP 的明确目标像素构建观测，二者功率与定标结果逐样本一致。
2. 使用 M1 观测定标，并反演 M4 三个隔离目标的显式像素观测。
3. 相同图像、身份、像素、斜距和孔径范围产生相同观测。
4. 修改观测身份不改变数学结果，但必须保留不同审计身份。
5. 边界外像素、归一化声明图像、零功率、空身份和逆序 pulse id 被拒绝。
6. 多点列表含任一无效观测时整次转换失败。
7. 受控联合干扰观测只记录辐射误差变化，不冻结有效性阈值。

## 8. 实现边界

- 首批内部模块放入 `src/sar/calibration`。
- 不修改 public target、mission、policy、output、Session 或 replay。
- 不增加自动标定目标选择、全局峰值搜索、主瓣积分、边缘门或 SNR 门。
- 不将观测标识解释为全局唯一数据库主键。
- 不开放归一化图像进入定标的路径。

## 9. 后续审批

显式观测实现完成后，再决定：

1. 是否接入受控 Session 内部管线。
2. 是否向 public 输出暴露摘要级定标 diagnostics。
3. 是否引入主瓣积分功率与自动像素定位。
4. 是否定义跨周期生命周期和 replay。
