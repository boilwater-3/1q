# SAR L3 航路点轨迹工程契约

## 1. 审批目标

建立可复现、可验证的 L3 折线/航路点轨迹几何能力，为后续非直线轨迹成像退化、时变 PRF 和高阶补偿研究提供输入证据。

本阶段只批准内部几何层能力，不接入 public Session。

## 2. L3 冻结定义

- 坐标继续使用 local Cartesian。
- 航路点由严格递增的显式时间和位置组成。
- 脉冲采样时刻由严格递增的显式时间序列提供，可表达固定或时变 PRF。
- 脉冲位置在相邻航路点间执行分段线性插值。
- 脉冲速度等于当前航段的常速度矢量。
- 每个脉冲必须具有连续 `pulse_id` 和对应的绝对 `time_s`。
- 脉冲时刻必须位于航路点时间覆盖范围内；禁止隐式外推。

## 3. 严格退化契约

当两个航路点描述 L1 匀速直线，且脉冲时刻为固定 `1/PRF` 序列时：

- L3 位置必须与 L1 逐点一致。
- L3 速度必须与 L1 逐点一致。
- `pulse_id` 与时间必须逐点一致。

## 4. 验收门

- 固定航路点和脉冲时刻重复生成结果逐点一致。
- 固定 PRF 直线航路点严格退化为 L1。
- 转角航路点在转角前后报告不同航段速度，并准确命中显式转角时刻。
- 非均匀脉冲时刻被保留，且位置插值正确。
- 拒绝少于两个航路点、非递增航路点时间、非递增脉冲时刻和越界脉冲时刻。
- C++11 + Eigen 3.3.9 和现有 SAR CI 继续通过。

## 5. 冻结边界

- 不接入 public Session、session config、runtime patch 或 replay。
- 不实现圆弧、样条、姿态、天线指向或 6DOF 动力学。
- 不将折线转角解释为物理可实现的瞬时转向；转角只作为确定性几何基准。
- 不实现时变 PRF 调度器，只消费显式脉冲时刻。
- 不实现 L3 RDA、BP、二阶运动补偿、自聚焦或 Auto。
- public Session `1024x1024` 和 GBP `128x128` 上限保持不变。

## 6. 后续审批顺序

1. L3 航路点轨迹几何与时变脉冲时刻。
2. 使用 L3 实际轨迹生成 raw echo，并量化相对 L1/RDA 的退化。
3. 基于 GBP/BP 或其他独立参考建立非直线轨迹成像真值。
4. 证据充分后，再讨论二阶残余误差校正或 public Session 接入。
