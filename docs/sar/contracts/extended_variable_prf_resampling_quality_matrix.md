# SAR 扩展时变 PRF 重采样质量矩阵契约

## 1. 目标

在现有中心单点、周期抖动质量矩阵基础上，增加多目标、高 Doppler 布局与固定 seed
随机小抖动证据。矩阵通过内部显式慢时间重采样执行器运行，不接入生产 RDA 或 Session。

## 2. 参考场景

- `E1`：M1 中心单点基线。
- `E2`：M4 二维分离多目标。
- `E3`：单点方位偏置场景，用于形成高于中心点的 Doppler 历史。

所有场景使用相同已审批参考场景基础、匹配滤波和 RDA 配置。E3 的方位偏置必须处于
现有参考网格与 raw-history 支持范围内。

## 3. 慢时间配置

每个场景至少执行：

- `J0`：均匀时刻，严格退化基线。
- `J1`：相对间隔幅度 `0.15` 的现有确定性周期抖动。
- `J2`：固定 seed `17`、相对间隔幅度 `0.05` 的确定性随机抖动。
- `J3`：固定 seed `17`、相对间隔幅度 `0.15` 的确定性随机抖动。
- `J4`：固定 seed `29`、相对间隔幅度 `0.15` 的确定性随机抖动哨兵。

随机抖动生成必须独立于平台和标准库随机实现，首尾时刻固定，结果有限且严格递增。
任何达到缺失脉冲间隙门的 case 必须被执行器拒绝，不得排序、补点或静默修复。

## 4. 执行链

1. 生成均匀参考 raw-history。
2. 按显式抖动时刻在同一 L1 轨迹上生成 jittered raw-history。
3. 构造内部显式请求并执行慢时间重采样执行器。
4. 仅在执行成功后使用相同 RDA 配置聚焦均匀与重采样 raw-history。
5. 记录执行器诊断和 raw-history/RDA 图像质量。

## 5. 指标

- 请求执行状态、拒绝原因与最大间隙比。
- 最大慢时间轴偏差和最大间隔偏差。
- raw-history 单位能量归一化 NRMS。
- RDA 图像全局相位对齐 NRMS 与相干相关系数。
- 场景、抖动类型、幅度与 seed。

## 6. 验收

1. `J0` 在 E1-E3 中严格退化，执行成功且质量误差为数值零。
2. J1-J4 均通过间隙门并完成重采样与 RDA，不产生部分输出。
3. 相同场景、类型、幅度和 seed 重复执行结果确定。
4. J2 与 J3 使用相同随机形状，J3 的最大时间偏差严格大于 J2。
5. 多目标和高 Doppler 场景全部记录有限有效指标。
6. 默认与 Eigen 3.3.9 环境测试及 C++11 门通过。

首批扩展矩阵记录质量测量，不据此冻结通用阈值，也不要求不同 seed 间单调。

## 7. 后置内容

- 生产 RDA、Session、public API、schema、trace、replay 和 Auto 接入。
- 缺失脉冲修复、稀疏恢复、NUFFT、sinc 或高阶重采样。
- 非 L1 轨迹和真实硬件时变 PRF 调度。
