# SAR L2 轨迹误差与一阶运动补偿工程契约

## 1. 审批目标

在不改变 Phase 1 public Session 默认 L1 轨迹的前提下，建立可复现的 L2 连续扰动轨迹、成像退化证据和一阶运动补偿闭环。

## 2. L2 轨迹冻结定义

- 坐标继续使用 local Cartesian。
- 理想轨迹为现有 L1 匀速直线条带轨迹。
- L2 为 L1 的超集：在标称 `x` 速度上叠加零均值扰动速度，并允许 `y/z` 横向速度扰动。
- 扰动使用显式固定种子生成，测试和 replay 可复现。
- 位置由速度逐脉冲积分生成，禁止对位置直接施加逐脉冲白噪声跳变。
- 零扰动配置必须与 L1 轨迹逐点一致。

## 3. 一阶运动补偿冻结定义

输入：

- 实际 L2 逐脉冲轨迹。
- 对应的理想 L1 逐脉冲轨迹。
- 单个显式参考点。
- 未补偿 raw pulse history。

处理：

1. 对每个脉冲计算参考点实际斜距 `R_actual` 与理想斜距 `R_ideal`。
2. 包络校正：按 `2*(R_actual-R_ideal)*Fs/c` 将实际 raw echo 平移到理想时延位置。
3. 相位校正：乘以 `exp(+j*4*pi*(R_actual-R_ideal)/lambda)`，恢复理想传播相位。
4. 距离插值第一版固定 linear；高阶插值后置。

输出诊断：

- 最大绝对斜距误差。
- RMS 斜距误差。
- 最大包络校正量，单位 bins。
- 越界样本数。
- 已补偿脉冲数。

## 4. 验收场景

- 固定种子 L2 轨迹重复生成必须逐点一致。
- 零扰动 L2 必须退化为 L1。
- 实际 L2 raw echo 使用未补偿 RDA 聚焦时，相对理想 L1/GBP 参考产生可测退化。
- 一阶补偿后，单位能量 NRMS 必须低于未补偿结果，且相干相关系数必须提高。
- 一阶补偿不得通过全局相位重参考掩盖空间变化误差。

## 5. 冻结边界

- public Session 默认仍使用 L1，不新增 L2 public 配置入口。
- 不实现 L3 曲线/机动轨迹。
- 不实现姿态误差、天线指向误差、IMU/GPS 测量误差和导航滤波。
- 不实现二阶运动补偿、自聚焦或 BP 自动选择。
- Auto 继续门禁。
- Phase 1 `1024x1024` public Session 上限和 GBP `128x128` 上限不变。

## 6. 分阶段审批

### 阶段 12：L2 契约冻结

- 本契约、计划和验收口径完成后提交。

### 阶段 13：L2 连续扰动轨迹

- 实现可复现连续扰动轨迹与轨迹误差诊断。
- 验证零扰动退化、固定种子重复性和非零扰动连续性。

### 阶段 14：一阶运动补偿闭环

- 实现包络与相位校正。
- 以理想 L1/GBP 参考证明补偿改善。
- 形成独立审批报告。
