# SAR Omega-K 全方位共同有效 Stolt 支持窗口诊断契约

## 1. 目标

基于已审批 Stolt 查询几何，诊断哪些目标距离频率列在全部方位 Doppler 行中均能查询
源频谱支持区，并给出最大连续共同有效窗口。首批只输出诊断，不自动裁剪或插值。

## 2. 输入与支持区

- 输入为有效的 `OmegaKGeometryConfig` 与对应 Stolt 查询几何。
- 源支持区为未 shift 距离频率轴按数值排序后的闭区间 `[f_min, f_max]`。
- 每个目标列对应所有方位行的一组源查询频率。
- 查询有限且位于闭支持区内时，该方位行上的该列有效。

## 3. 共同有效列

目标列 `r` 仅在所有方位行都有效时标记为共同有效：

$$
valid[r] = \bigwedge_a \left(f_{min} \le q[a,r] \le f_{max}\right)
$$

共同有效掩码保持原未 shift 目标列顺序。由于该顺序在频率值上不连续，诊断还必须基于
按频率值排序后的目标列计算最大连续共同有效窗口，并明确返回对应原始列索引集合。

## 4. 诊断

至少记录：

- 方位行数、目标列数和总查询数；
- 每列越支持区查询数；
- 共同有效列掩码与列数；
- 最大连续共同有效窗口的最小/最大频率、列数和原始列索引；
- 丢弃列数与共同有效比例；
- 最大绝对 Stolt shift；
- 是否存在可用于后续插值的至少两列连续窗口。

## 5. 失败与边界

- 配置、几何形状、查询数量或频率非有限时结构化拒绝。
- 没有共同有效列或最大连续窗口少于两列时诊断有效，但标记不可用于插值。
- 边界查询等于 `f_min` 或 `f_max` 时有效。
- 不自动选择非连续列拼接，不改变目标频率间隔，不执行补零或外推。

## 6. 首批验收

1. 零 Doppler 单行时所有目标列共同有效。
2. 完整多 Doppler 网格识别高频边界越界并形成共同有效窗口。
3. 正负 Doppler 对称输入产生相同逐列越界计数贡献。
4. 支持区边界查询保留，越过边界的查询拒绝。
5. 输入不变，重复诊断确定。
6. 默认与 Eigen 3.3.9 环境测试及 C++11 门通过。

## 7. 后置内容

- 自动目标网格收缩、裁剪后插值和输出距离轴重定义。
- 完整 Omega-K 参考相位、二维 IFFT、聚焦入口与生产接入。
