# SAR CSA 完整相位函数与中间域参考真值工程契约

## 1. 目标

为完整 Chirp Scaling Algorithm 建立可审计的相位函数审批入口。仓库现有材料只冻结
频率轴、`D(f_a)`、`alpha(f_a)` 和高层六步流程，没有给出足以直接编码的完整相位
公式。因此本契约不臆测公式系数，而是冻结完整公式参考包必须满足的结构、处理域、
逐阶段复数真值和验收规则。

完整 CSA 聚焦入口只有在参考包逐阶段通过后才允许实现。

## 2. 输入边界

- L1 匀速直线 broadside 条带模式。
- 均匀 PRF、均匀距离采样和完整二维 raw-history。
- 行主序矩阵：行表示方位脉冲，列表示距离采样。
- 正载频、采样率、PRF、平台速度、参考斜距和距离 chirp rate。
- 复数双精度；频率轴复用 `SarCsaGeometry` 的未 shift 约定。
- forward FFT 不归一化，inverse FFT 除以对应轴长度。

L2/L3、斜视、聚束、时变 PRF、缺失脉冲、运动补偿和自聚焦不进入首批参考包。

## 3. 完整公式审批包

每个参考包必须显式包含：

1. 唯一 reference id 与来源说明。
2. 全部标量配置与输入复数矩阵。
3. 三类完整复数单位模相位核：
   - 第一 chirp-scaling 相位核；
   - 距离压缩、SRC 与 RCMC 合并相位核；
   - 方位压缩与残余相位校正核。
4. 每个相位核的精确处理域、矩阵形状、索引轴和符号约定。
5. FFT/IFFT 与相位相乘的完整有序操作列表。
6. 每一步操作后的固定复数期望矩阵。
7. 最终输出的相位参考与幅度归一化说明。

相位核必须逐样本有限，且幅度在数值容差内等于 `1`。禁止只提供相位角而省略复指数
符号，也禁止只提供最终聚焦图像。

## 4. 中间域操作模型

首批真值执行器只允许以下确定性操作：

- `kForwardRangeFft`：逐行 forward FFT。
- `kInverseRangeFft`：逐行 inverse FFT。
- `kForwardAzimuthFft`：逐列 forward FFT。
- `kInverseAzimuthFft`：逐列 inverse FFT。
- `kMultiplyPhaseKernel`：与同形状复数单位模相位核逐样本相乘。

参考包必须显式给出操作顺序。执行器不得根据核名称猜测处理域，不得自动转置、shift、
补零、归一化或重排操作。若经审计公式与现有设计文档的高层六步顺序不一致，应先修订
设计文档，再批准参考包。

## 5. 逐阶段真值

每个操作都必须对应一个期望阶段：

- stage id 和 operation；
- 输入/输出形状；
- 可选 phase-kernel id；
- 完整期望复数矩阵；
- 最大绝对误差与单位能量归一化 NRMS 容差。

首批固定小矩阵使用严格可重复真值：

- 单位冲激：验证 FFT 轴、归一化和操作顺序。
- 可分离复指数：验证未 shift bin 与正负频率符号。
- 非对称确定性复数矩阵：发现转置、轴交换和共轭错误。
- 单点参考 raw-history：用于后续与 GBP/RDA 最终质量交叉核对。

中间阶段是主审批证据；最终峰值、图像 NRMS 或相关系数只能作为补充。

## 6. 失败语义

以下情况必须原子拒绝，且不返回部分最终图像：

- reference id、输入矩阵、操作列表或期望阶段为空；
- 操作与期望阶段数量不一致；
- 相位核缺失、形状不匹配、样本非有限或非单位模；
- FFT/IFFT 输入形状无效；
- operation 不支持或 phase-kernel id 不匹配；
- 任一阶段超过已冻结误差容差；
- `SarCsaGeometry` 报告无效 Doppler bin。

拒绝结果必须指出首个失败 stage id 和结构化原因。

## 7. 首批验收

1. 真值执行器可重放合法操作列表并逐阶段比较固定复数矩阵。
2. 单位冲激、复指数和非对称矩阵能检出轴、符号、转置、共轭和归一化错误。
3. 非单位模、非有限、形状错误、顺序错误和真值偏差均明确拒绝。
4. 相同参考包重复执行结果确定，输入与参考包保持不变。
5. 默认与 Eigen 3.3.9 环境测试及 C++11 门通过。
