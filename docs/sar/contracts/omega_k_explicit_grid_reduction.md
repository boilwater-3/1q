# SAR Omega-K 显式 Stolt 目标网格收缩请求契约

## 1. 目标

将共同支持窗口诊断与复数 Stolt 插值组合为可审计的内部显式请求。请求提取最大连续
共同有效目标距离频率窗口，对该窗口执行插值，并返回收缩后的频谱与频率轴。

## 2. 请求

请求必须显式包含：

- 非零 request id；
- 原始源距离频率轴与二维复数源频谱；
- 已计算的 Stolt 几何与共同支持诊断；
- 明确选择 `largest_contiguous_common_support`。

首批不允许调用方传入任意列集合或自定义窗口。

## 3. 执行顺序

1. 验证请求、几何、支持诊断与源频谱形状一致。
2. 验证共同窗口至少两列且所有列均标记共同有效。
3. 按共同窗口频率升序提取目标频率轴和每个方位行的查询矩阵。
4. 调用复数 Stolt 线性插值器。
5. 成功后原子返回收缩频谱、目标频率轴和原始列索引。

## 4. 输出

- request id、执行状态与结构化拒绝原因；
- 收缩后的目标距离频率轴，严格递增；
- 对应原未 shift 目标网格的列索引；
- 与输入方位行数相同、列数等于窗口列数的复数频谱；
- 共同支持与插值诊断摘要。

## 5. 拒绝语义

以下情况输出为空：

- 请求 id、源轴、频谱、几何或支持诊断无效；
- 形状或列索引不一致；
- 共同窗口少于两列、非连续、非共同有效或非严格频率递增；
- 提取查询越界或 Stolt 插值失败。

## 6. 首批验收

1. 完整多 Doppler 几何可通过显式收缩请求完成支持区内插值。
2. 输出频率轴严格递增，原始列索引与共同支持诊断一致。
3. 仿射复数谱在收缩网格上精确恢复。
4. 无窗口、篡改索引、形状错误和无效请求明确拒绝。
5. 输入不变，相同请求重复执行确定。
6. 默认与 Eigen 3.3.9 环境测试及 C++11 门通过。

## 7. 后置内容
