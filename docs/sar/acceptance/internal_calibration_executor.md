# SAR Session 内部显式校准执行器审批报告

## 1. 审批结论

阶段 64 内部显式校准执行器已完成当前平台审批。

- 无状态执行器可消费显式路径、请求列表和未归一化复图像。
- 请求路径与实际图像路径严格匹配。
- 空列表、路径不匹配、越界像素和无效请求返回结构化失败。
- 任一请求失败时不产生部分残差或部分定标结果。
- M1 RDA、GBP 与 BP 路径均可执行；GBP/BP 定标因子一致。
- 定标失败不修改原聚焦图像，也不触发算法回退。

## 2. 验证结果

- 默认环境执行器与定标测试：`7/7 passed`。
- Conan Eigen 3.3.9 执行器与定标测试：`7/7 passed`。
- 默认 Windows Debug 完整 CTest：`25/25 passed`。
- Conan Eigen 3.3.9 `sar_cxx11_compat`：`1/1 passed`。

## 3. 冻结边界

- 当前执行器仍为 `src/sar/calibration` 内部能力。
- 不修改 `SarSession`、public API、schema、trace 或 replay。
- 不自动选择目标、像素或聚焦算法。
- 不引入主瓣积分、有效性阈值、算法回退或 Auto。

## 4. 下一阶段建议

进入内部执行器后续接入决策门，判断是否已有足够证据将显式请求受控接入
`SarSession` 内部管线，或继续保持独立内部能力。
