# SAR CSA 中间域真值执行器验收报告

日期：2026-06-11

## 验收范围

阶段 101 实现内部 CSA 中间域真值执行器。执行器重放参考包显式操作列表，逐阶段比较
固定复数期望矩阵，并在首个结构或真值错误处原子拒绝。

本阶段不实现具体 CSA 相位公式、完整 CSA 聚焦入口、选择器或 Session 接入。

## 实现结果

- 支持逐行/逐列 forward FFT 与 inverse FFT。
- 支持同形状复数单位模相位核逐样本相乘。
- 对每个阶段记录最大绝对误差、单位能量 NRMS 和通过状态。
- 对无效 reference、输入、阶段、相位核、操作失败和真值偏差返回独立拒绝原因。
- 拒绝时最终输出为空；相同参考包重复执行结果确定且输入不变。

## 测试覆盖

- 显式冲激、相位核、方位/距离 FFT 操作链重放。
- 非对称复数矩阵距离 FFT 往返，验证符号、轴与 inverse 归一化。
- 非单位模相位核拒绝与最终输出原子性。
- 首个真值偏差定位与阶段诊断。
- 确定性和参考包输入不变。

## 验证证据

- 默认环境 `SarCsaIntermediateTruthTest.*`：5/5 passed。
- Eigen 3.3.9 环境 `SarCsaIntermediateTruthTest.*`：5/5 passed。
- 默认环境完整 CTest：25/25 passed。
- Eigen 3.3.9 构建：passed。
- Eigen 3.3.9 `sar_cxx11_compat`：1/1 passed。

## 验收结论

阶段 101 在当前平台通过。执行器已提供完整 CSA 相位公式参考包的逐阶段审批能力；
在经审计公式和固定中间域真值进入仓库前，完整 CSA 聚焦仍不批准。
