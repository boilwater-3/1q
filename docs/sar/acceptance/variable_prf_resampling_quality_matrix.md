# SAR 时变 PRF 重采样质量参考矩阵验收报告

## 1. 验收范围

本阶段使用固定单点参考场景，验证确定性慢时间抖动经二维线性重采样后的 raw-history
与 RDA 图像误差趋势。不批准生产 RDA 接入。

## 2. 测量结果

| 抖动比例 A | raw-history NRMS | RDA 图像 NRMS |
|---:|---:|---:|
| 0.00 | 约 0 | 约 0 |
| 0.05 | 0.000164 | 0.000090 |
| 0.15 | 0.000463 | 0.000254 |
| 0.35 | 0.000947 | 0.000526 |

相干相关系数在六位小数记录精度下均接近 `1.000000`，内部全精度比较仍满足小抖动优于
大抖动的趋势。

## 3. 验证结果

- 默认与 Eigen 3.3.9 `SarVariablePrfQualityMatrixTest.*`：各 `1/1` passed。
- 默认完整 CTest：`25/25` passed。
- Eigen 3.3.9 `sar_cxx11_compat`：`1/1` passed。
- `git diff --check`：passed。

## 4. 已解决问题

- 修正测试使用的 RDA 输出类型名。
- 零抖动派生 NRMS 存在 `1e-16` 量级舍入误差，改用数值零容差。
- GoogleTest 数值属性重载截断小数，改为字符串记录测量值。

## 5. 审批结论

时变 PRF 重采样质量矩阵完成当前平台审批。当前单场景证据显示误差随抖动稳定增大，
但不足以冻结通用接入阈值；缺失脉冲、多目标和更高 Doppler 场景继续后置。
