# SAR Omega-K 收缩频谱相对延迟变换执行器验收报告

日期：2026-06-11

## 验收范围

阶段 112 实现内部收缩频谱相对延迟变换执行器。执行器验证均匀收缩频率轴和复数频谱，
逐行执行 inverse FFT，并原子返回相对延迟轴诊断与距离时域矩阵。

## 实现结果

- 显式 request id、收缩频率轴和复数频谱请求。
- 复用收缩频率轴诊断，逐方位频率行执行 inverse-range FFT。
- 成功时返回周期性相对延迟轴与同形状距离时域矩阵。
- 无效请求、频率轴、频谱或变换失败时输出为空。
- 输入不变，相同请求重复执行确定。
