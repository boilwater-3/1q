# SAR Omega-K 显式 Stolt 目标网格收缩请求验收报告

日期：2026-06-11

## 验收范围

阶段 108 实现内部显式最大连续共同支持窗口收缩执行器。执行器提取共同窗口查询，
调用复数 Stolt 插值器，并返回严格递增目标频率轴、原始列索引和收缩频谱。

## 实现结果

- 只接受共同支持诊断给出的最大连续窗口。
- 输出目标频率轴严格递增，并保留原未 shift 目标列索引。
- 支持源谱列数与收缩目标查询列数不同的 Stolt 插值。
- 结构、支持窗口或插值失败时输出原子为空。
- 相同请求重复执行结果确定，输入不变。

## 测试与修正

- 完整多 Doppler 几何经显式收缩后可完成支持区内插值。
- 仿射复数谱在收缩网格上按查询频率精确恢复。
- 篡改共同支持掩码、无效 request id 和源谱形状明确拒绝。
- 首次回归触发容器越界，根因是插值器输出已允许目标列数收缩，但内部列循环仍使用源
  频谱列数；修正为查询矩阵列数后完整回归通过。

## 验证证据

- 默认环境完整 CTest：25/25 passed。
- 默认完整 CTest 覆盖 `SarOmegaKGridReductionTest.*` 全部 3 个测试。
- Eigen 3.3.9 构建与 C++11 门：passed。
- Eigen 运行记录待审批通道恢复后补充。

## 验收结论

阶段 108 当前平台默认环境通过。执行器仅批准为内部显式频率域收缩能力；收缩后空间
域距离轴、参考相位、二维 IFFT、完整 Omega-K 聚焦和生产接入继续后置。
