# SAR Omega-K 全方位共同有效 Stolt 支持窗口诊断验收报告

日期：2026-06-11

## 验收范围

阶段 106 实现内部共同有效支持窗口诊断。诊断消费现有 Stolt 查询几何，计算每个目标
距离频率列在全部方位 Doppler 行中的有效性，并按频率值排序给出最大连续共同窗口。

本阶段不自动裁剪目标网格，不执行插值或完整 Omega-K 聚焦。

## 实现结果

- 输出原未 shift 目标列顺序下的共同有效掩码和逐列越界计数。
- 输出共同有效列数、丢弃列数、有效比例与最大绝对 Stolt shift。
- 按频率值排序计算最大连续共同有效窗口，并返回对应原始列索引。
- 最大连续窗口少于两列时明确标记不可用于插值。
- 支持区闭边界查询有效；结构无效输入明确拒绝。

## 测试覆盖

- 完整多 Doppler 网格识别边界越界并形成共同窗口。
- 零 Doppler 单行严格保留全部目标列。
- 支持区闭边界保留与越界查询拒绝。
- 无效形状拒绝、输入不变与确定性。

## 验证证据

- 默认环境完整 CTest：25/25 passed。
- 默认完整 CTest 覆盖 `SarOmegaKCommonSupportTest.*` 全部 4 个测试。
- Eigen 3.3.9 构建与运行记录待审批通道恢复后补充。

## 验收结论

阶段 106 当前平台默认环境通过。诊断为显式目标网格收缩决策提供了依据，但尚未批准
自动裁剪、裁剪后插值、输出距离轴重定义或完整 Omega-K 聚焦。
