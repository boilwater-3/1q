# Target Inference 算法

## 算法清单

| 算法 | 输入 | 输出 | 证据 |
|---|---|---|---|
| 弹道前向外推（RK4） | ECEF 状态 + 配置 | 航迹点序列 + 落点（地表交点线性插值） | `src/target_inference/TargetInferenceEngine.cpp`；`tests/unit/target_inference/target_inference_engine_test.cpp` |
| 发射点回推 | ECEF 状态 + 配置 | 发射点/时间（地表交点或速度停机门） | 同上 |
| 敏度误差预算（J·P·Jᵀ） | 输入协方差 + 扰动重推 | 发射 6×6 协方差 + 发射/落点 1-σ | 同上 |
| 类型融合（先验 + 证据加权） | 速度/高度 + 可选证据向量 | 大类 + 归一化概率 | 同上 |

## 1. 弹道积分与回推

- 动力学：中心引力 `a = −μ·r/|r|³` + 可选指数大气阻力（`drag_ballistic_coefficient_
  m2_per_kg ≤ 0` 关闭；ρ = 1.225·exp(−alt/8500)）。
- 积分器：定步长 RK4，`dt` 可为负（回推即负向积分）；步长 `integration_step_sec`。
- 落点：前向步进中 |r| 跨越地表半径 → 相邻步线性插值交点。
- 发射点：回推步进至地表交点（插值）或速度 ≤ `launch_speed_threshold_m_per_s`；
  超过 `launch_max_backtrack_sec` 未触发 → `has_launch=false`。

### 实现边界

- 助推段未建模：真空/阻力弹道回推到地表即"发射点"——对助推段长的目标存在系统性
  偏差，由误差预算部分承载；燃烧段模型为后续冻结项。
- 守恒律是正确性门：无阻力下单测验证能量 `v²/2 − μ/|r|` 漂移 < 0.1%。

## 2. 敏度误差预算

- 发射协方差：6 个扰动态（固定步长 位置 100 m / 速度 1 m/s）重推回推轨线，得
  6×6 敏度 J；`Σ_launch = J·P·Jᵀ`（完整非对角）。1-σ 取位置对角块最大方差开方。
- 落点 1-σ：同一框架的前向敏度，对角占优近似（Σ_j H_ij²·P_jj）——证据级口径，
  完整 J·P·Jᵀ 为后续冻结项。
- 动力学对扰动步长不敏感（平滑场），固定步长保证确定性。

### 反直觉点

- **σ=0 不是零误差**：输入无协方差时产品 σ 为 0 且 `has_uncertainty=false`——
  这是"无预算"标记，消费方必须区分。
- **误差预算随回推时域增长**：发射点 σ 通常大于当前状态 σ（敏度矩阵范数 > 1），
  这是回推放大的线性化表达；P0 实测表明匹配模型下相关误差部分抵消，放大系数
  ~1（见 target_domain_p0_p1_decision §4.2 结论 3），两口径不矛盾（此处为线性
  上界语义）。

## 3. 类型融合

- 运动学先验（速度/高度门判，8 类得分向量）：
  - 高能量（≥ `high_energy_speed_threshold`）且高空（≥ `high_altitude_threshold`）：
    弹道 0.55 / 导弹 0.30 / 临近空间 0.10；
  - 高能量低空：导弹 0.45 / 战斗机 0.20 / 其它 0.15；
  - 中速（500 ~ 高能量门）：战斗机 0.35 / 轰炸机 0.25 / 其它 0.20；
  - 低速：无人机 0.35 / 其它 0.30 / 战斗机 0.10。
- 融合：`s = w·prior + (1−w)·evidence`（w = `kinematic_type_weight`，默认 0.5）；
  无证据时 s = prior。概率 = s_max/Σs，类别 = argmax。

### 反直觉点

- 先验是**门判启发式不是分类器**：目的是给无识别源的目标一个诚实的运动学倾向；
  有证据时权重可配；阈值门为硬编码业务决策（示例场景验证过），不做配置面
  （YAGNI，同 fusion 适配器先例）。
- **证据通道是多源可组合的预留口**：type_evidence 当前通常由 RIR 识别结论（经
  TARGET-OQ-4 方案 a 键映射）组装；RIR 双产品出口①（特征量测帧，2026-08-18 裁定
  采纳并已于同日 Stage B 落地）上线后，特征级证据可多源组合——组合逻辑归调用方/
  未来识别算法面，本模块只消费得分向量，不感知证据来源。
