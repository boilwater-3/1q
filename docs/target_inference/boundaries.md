# Target Inference 模块边界

## 输入输出边界（冻结）

1. 输入为泛型航迹帧（`InferenceTrackState`：ECEF 状态 + 可选协方差 + 可选类型证据），
   不引用 fusion/传感器任何类型；对接由调用方值级组装。
2. 输出必须携带误差预算（发射/落点 1-σ + 发射点 6×6 协方差）；无协方差输入显式
   `has_uncertainty=false`，不得输出裸点估计冒充确定结论（契约规则 6）。
3. 类型证据语义：按本模块泛型大类枚举的 [0,1] 得分向量；具体传感器识别枚举到本
   枚举的映射归调用方（RIR 走 TARGET-OQ-4 方案 a 键映射）。
4. 引擎无跨调用状态、逐航迹独立；同输入同输出（确定性、可 replay 语义由纯函数保证）。

## 非目标

1. 不做关联/滤波（估计层职责）；不做威胁评分（决策层职责）。
2. 不建 Session/周期/事件总线形态；不接入 Recording/Replay 框架（纯函数面）。
3. 不建模助推段动力学——发射点定义为回推弹道与地表交点（或速度停机门），
   助推段燃烧模型为后续冻结项。
4. 不做 IMM/多假设弹道模型、不做在线参数辨识（弹道系数为配置输入非估计量）。
5. 不引入新第三方依赖（RK4/线性代数均为库内手写）。

## 设计变更规则

1. 弹道模型（引力/阻力/积分器/停机门）变化必须同步 algorithms.md 实现边界与
   单测的守恒律/往返一致性门。
2. 误差预算口径变化（敏度框架/协方差排列）必须同步 InferenceResult.h 契约注释、
   algorithms.md 与 `target_inference_engine_test` 的 σ 门。
3. 类型融合公式变化必须同步 algorithms.md 反直觉点与类型融合单测。
4. 公共头新增/重排按 public API 变更流程（追加不重排，枚举加性扩展）。
