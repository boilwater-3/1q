# SAR L3 一阶运动补偿适用性审计报告

## 1. 审批结论

现有单参考点一阶运动补偿在当前 `9x9` 小场景 L3 折线轨迹上有效，可作为内部研究路径继续使用。

- 参考点成像质量显著改善：通过。
- 偏离参考点目标存在空间变化残余：确认。
- 当前残余量不足以证明二阶补偿、多参考点或 BP 的必要性。
- public L3、时变 PRF 成像、二阶补偿、BP 和 Auto：继续后置。

## 2. 质量证据

相对 L3-GBP：

| 指标 | 未补偿 L3-RDA | 一阶补偿后 L3-RDA |
|---|---:|---:|
| 单位能量 NRMS | `0.501878` | `0.185881` |
| 相干相关系数 | `0.874059` | `0.982724` |

一阶补偿后满足当前内部小场景门：NRMS `< 0.25`，相干相关系数 `> 0.97`。

## 3. 空间变化残余

- 一阶补偿参考点位于中心距离单元。
- 对偏离参考点的目标，最大剩余斜距误差约 `0.000180 m`。
- 残余非零，证明单参考点补偿不是全场景精确解。
- 当前残余小于 `0.001 m`，不足以支持立即引入多参考点或二阶补偿。

## 4. 冻结边界

- 审批只覆盖当前确定性 `9x9` 小场景和固定 PRF。
- 不推断到更大孔径、更大场景跨度、更强转弯或时变 PRF。
- 不接入 public Session。
- 不批准二阶补偿、多参考点、BP、自聚焦或 Auto。

## 5. 验证结果

- 默认与 Eigen 3.3.9 L3/GBP/补偿/RDA/Session 过滤测试：各 `33/33 passed`。
- `ctest -L sar_ci`：`4/4 passed`。
- `ctest -L sar_performance`：`1/1 passed`。
- Eigen 3.3.9 `sar_cxx11_compat`：`1/1 passed`。
- `git diff --check`：passed。

## 6. 下一阶段建议

建立 L3 适用边界矩阵，至少扫描转弯横向偏移和目标相对参考点距离，量化一阶补偿质量与空间变化残余随场景参数的变化。矩阵证据出现明确失效区后，再决定多参考点、BP 或二阶补偿方向。
