# Threat Assessment 模块边界

本文承载 threat_assessment 的模块级边界、非目标和变更规则。算法级边界与反直觉点见
[algorithms.md](algorithms.md)，选型与双向评估决策记录见
`docs/review/threat_assessment_decision_2026-08-10.md`。

## 输入边界（冻结）

1. **泛型输入帧**：`ThreatEvaluationInput` 为纯属性帧（速度/距离/加速度/RCS/
   类型概率/融合置信度），算法不感知传感器类型与坐标系；距离由调用方计算
   （目标到受保护资产/平台的斜距），本模块不做任何坐标变换。
2. **融合置信度语义（冻结）**：`fusion_confidence` 来自 `FusionTarget` 的冻结
   公式（滑窗精确求和、不归一化、可 >1），本模块内部钳制到 [0,1] 后作为
   "证据强度"属性；语义变化须同步 `docs/fusion/algorithms.md`。
3. **属性缺失语义（冻结）**：NaN/负值按属性缺失处理（归一化 0，贡献为 0）；
   0 是合法属性值（距离 0 = 零距离满分）；输入帧不设"是否提供该属性"标志——
   缺失以 NaN/负值表达，inf 按超界钳制。

## 非目标

1. **不做其他算法流派**：D-S 证据理论/证据推理、贝叶斯网络/DBN、神经网络/深度学习、
   TOPSIS/VIKOR、灰色关联、模糊推理、直觉模糊集族——本首期仅归一化加权和
   （选型与对比见决策记录 §4）。
2. **不做武器分配/拦截策略**（TEWA 的 WA 部分）——只出威胁分与等级。
3. **不做跨周期状态**：无历史/平滑/记忆，跨周期信息由调用方组装进输入帧。
4. **不预测未来**（意图/轨迹外推）——仅评估当前帧属性。
5. **不做编队规模/群目标与高度属性**——文献常用但本首期不引入（未来冻结项）。
6. **不解析场景真值、不建外部身份通道**（守去真值化纪律，与 fusion 一致）。
7. **不与 AR 决策层 `ThreatAssessmentEvaluator` 合并**：既有启发式服务单传感器
   路径，本算法面服务融合态势路径，各自保留。

## 设计变更规则

1. 属性集合、归一化断点语义或等级映射阈值变化必须同步本文档集与决策记录
   （`docs/review/threat_assessment_decision_2026-08-10.md`）冻结项。
2. 若引入新的算法流派（如 D-S 折扣消费融合置信度），必须先走"证据优先开发模式"
   （`docs/common/contract.md`）Stage A 证据矩阵，并评估对
   `fusion`/`airborne_radar::decision` 既有实现的复用路径。
3. 若引入跨周期状态（平滑/记忆），必须重新评估纯函数式边界（冻结项 F4）。
4. 公开 API 扩展（新属性/新输出字段）须同步聚合头与单测。
