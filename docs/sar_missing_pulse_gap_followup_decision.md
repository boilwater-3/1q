# SAR 缺失脉冲诊断后续接入决策

## 1. 决策结论

缺失脉冲间隙诊断可接入内部参考质量链，但暂不接入生产 RDA 或 Session。下一阶段建立
缺失脉冲拒绝参考矩阵，验证门禁在插值和聚焦前停止。

## 2. expected interval 来源审计

- 固定参考场景中的 `scene.prf_hz` 可明确提供 `1/prf`，适合作为测试真值。
- 内部显式算法配置中的固定 `prf_hz` 可作为未来门禁来源。
- Session 当前硬件配置只有固定 PRF，缺少已审批的显式时变 PRF/缺失脉冲请求语义。
- 不允许从缺失后的首尾跨度或样本数猜测 expected interval。

## 3. 接入边界

- 允许在内部参考质量链中使用门禁包装入口。
- 不接入 RDA 默认路径、Session、public API、schema、trace 或 replay。
- 不自动修复、补点或排序。

## 4. 下一方向

下一阶段使用固定参考场景构造零缺失、单缺失和多缺失 case，验证门禁允许正常 case，
拒绝缺失 case，并保证被拒绝 case 不产生重采样输出或 RDA 图像。
