# SAR Phase 2 参考级成像与算法对比闭环综合再审批报告

## 1. 综合审批结论

Phase 2 在当前“固定 PRF、点目标、显式算法路径”边界内完成参考级成像与算法对比闭环综合再审批。

当前批准：

- public L1 broadside RDA + linear RCMC，保持 `1024x1024` 当前平台上限。
- public L2 固定种子连续扰动轨迹与显式一阶运动补偿。
- public L3 固定 PRF waypoint 轨迹与显式 BP，保持 `128x128` 上限。
- 内部 GBP/BP 参考路径、统一复图比较与质量指标。
- 边界、参数、方位采样、孔径相位跨度和目标方位偏置决策矩阵。

当前不批准：

- Auto、隐式算法回退或基于 diagnostics 的质量拒绝。
- RDA `1024x1024` 或 GBP/BP `128x128` 尺寸门扩大。
- 时变 PRF、真实动力学轨迹、二阶/多参考点补偿、自聚焦。
- 全图复数矩阵 replay。
- 噪声、杂波、辐射定标或通用场景质量声明。

## 2. 已闭环证据

| 能力 | 当前证据 | 审批边界 |
|---|---|---|
| L1 RDA | 中心、距离/方位偏置、二维多目标、边界与参数矩阵 | broadside、固定 PRF、点目标 |
| GBP/BP 参考 | L1/L3 复图参考，BP 与 GBP 逐样本一致 | 任一维不超过 `128` |
| L2 一阶补偿 | 零扰动严格退化，固定 seed 扰动显著改善 | 单参考点、一阶补偿 |
| L3 BP | waypoint、跨周期 aperture、结构化拒绝与 replay | 固定 PRF、显式启用 |
| RDA 解释性 diagnostics | 采样间距、相位曲率、孔径二次相位跨度、Nyquist 裕量 | 解释性输出，不作为阈值 |
| 工程门 | 默认与 Conan Eigen 3.3.9、C++11、CI、性能 | 当前平台与冻结尺寸门 |

## 3. Auto 再审批

Auto 继续不批准：

1. RDA 与 BP 的适用域、尺寸门和 public 启用条件不同。
2. GBP 仍是内部参考路径，不能作为 public 自动降级目标。
3. 当前解释性 diagnostics 不能形成通用质量阈值。
4. 当前算法比较仍以无噪声点目标为主，缺少 SNR 鲁棒性证据。
5. 尚未冻结选择阈值、降级规则、选择诊断和 replay 语义。

## 4. 主要剩余缺口

按当前参考级成像主线，最高优先级缺口是无噪声点目标证据无法回答：

- 质量指标在不同 SNR 下是否保持稳定和可解释。
- RDA/GBP/BP 比较是否会被噪声主导。
- 当前 NRMS、相关系数、PSLR、ISLR、宽度和熵指标在低 SNR 下何时失去判别力。

分布式杂波、辐射定标、时变 PRF和真实动力学轨迹均需要更大合同面，不应先于基础 SNR 鲁棒性矩阵。

## 5. 下一扩展方向

批准下一阶段进入“确定性噪声与 SNR 鲁棒性参考矩阵”：

- 只在测试支持层增加固定 seed 复高斯噪声注入。
- 首批只覆盖 L1 RDA/GBP/BP 参考场景和统一质量指标。
- 不增加 public 配置、runtime patch、replay 字段或生产算法分支。
- 不把首批 SNR 结果直接转化为 Auto、质量警告或结构化拒绝。
