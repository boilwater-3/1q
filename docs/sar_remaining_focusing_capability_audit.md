# SAR 剩余聚焦能力审计

## 1. 审计结论

阶段 66 选择“内部确定性聚焦算法选择器”作为下一实现线。选择器首批只在已经审批的
RDA、GBP、BP 之间给出可解释建议，不接入 public `Auto`，也不自动执行或回退算法。

CSA、Omega-K、自聚焦和时变 PRF 成像继续后置。

## 2. 当前能力基线

- RDA 已完成 L1 固定 PRF、边界参数、采样诊断、噪声/杂波和辐射定标矩阵。
- GBP 已完成小场景独立参考真值、质量与性能验收。
- BP 已完成 L3 失效区、public 显式路径和 GBP 一致性验收。
- L2 一阶补偿和 L3 轨迹适用边界已有明确通过区与失效区。

## 3. 候选能力审计

### CSA

暂缓。当前方案仅描述高层流程，尚未冻结二维频率轴、参考距离、chirp scaling 相位项、
RCMC 等效关系和独立参考结果。

### Omega-K

暂缓。需要冻结二维频谱、参考函数、Stolt 映射、插值核、越界行为和独立真值，当前
实现前置条件不足。

### 自聚焦

暂缓。当前没有冻结可观测残余相位误差模型、PGA 输入支持区和相对独立真值；不能只以
图像熵下降宣称修复。

### 时变 PRF 成像

暂缓。几何层已经支持显式脉冲时刻，但 RDA 的 Doppler 频率轴和 FFT 处理仍假设均匀
PRF。进入实现前需先冻结非均匀慢时间重采样或 NUFFT 策略。

### 内部确定性聚焦算法选择器

选择。RDA、GBP、BP 已具备明确适用边界、尺寸门、质量证据和性能基准，可以先建立
不执行算法的内部建议器，验证决策可解释性和拒绝语义。

## 4. 下一阶段边界

- 首批选择器输入只使用显式轨迹等级、算法可用性、场景尺寸和调用方目的。
- 输出为建议算法、决策原因和拒绝原因。
- 选择器不运行算法、不修改请求、不触发回退。
- GBP 只允许作为内部参考目的建议，不作为常规 Session 自动路径。
- public `Auto`、runtime patch、schema、trace 和 replay 继续后置。
