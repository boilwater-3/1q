# Stage 02 Roadmap

## Purpose

本文件用于记录 ESR 第二阶段迭代项。当前阶段只完成“周期级体制共享内核”抽象，把 airborne_radar 与 electronic_surveillance_radar 的 `pulse_count / PRF / dt-PRI` 这类周期级时序逻辑收敛到私有 `common/timing`。  
以下内容明确延后，不属于本轮实现范围。

## Deferred ESR Timing Work

### 1. 更细的发射源体制建模

- 扫描推进与驻留：由内部状态推进 `beam_state`，而不是完全依赖场景侧逐周期手填。
- 占空比与开机/停机节奏：区分“场景存在发射源”和“本周期确实在辐射”。
- 周期级扫描覆盖与截获窗口：把“是否照到平台”从静态角度门控推进到扫描状态驱动。

### 2. 更丰富的 PRI/PRF 行为

- 固定 PRI 与抖动 PRI 的区分建模。
- 脉组、突发、占空比控制等更丰富的周期级发射节奏。
- 基于 `dt / pri` 之外的体制特征摘要，为后续识别链提供更稳定输入。

### 3. 更强的识别与反欺骗

- 基于 `RF / PW / PRI / scan behavior` 的联合识别，而不是仅依赖当前简化阈值规则。
- 欺骗样式库细化：支持更明确的虚警、错分选、错识别模式。
- 反欺骗先验与稳健关联策略增强，避免复杂干扰下系统性偏乐观。

## Escalation Boundary

仅当第二阶段的周期级体制建模和识别链仍不足以支撑目标推演时，才考虑更重的“脉冲序列级发射机”建模。  
在此之前，优先保持工程基线可解释、可复现、可测试。
