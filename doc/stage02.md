# Stage 02 Roadmap

## Purpose

本文件用于记录 ESR 第二阶段迭代项。当前阶段只完成“周期级体制共享内核”抽象，把 airborne_radar 与 electronic_surveillance_radar 的 `pulse_count / PRF / dt-PRI` 这类周期级时序逻辑收敛到私有 `common/timing`。  
以下内容明确延后，不属于本轮实现范围。

## Deferred ESR Timing Work

### 1. 更细的发射源体制建模

- 扫描推进与驻留：由内部状态推进 `beam_state`，而不是完全依赖场景侧逐周期手填。
- 占空比与开机/停机节奏：区分“场景存在发射源”和“本周期确实在辐射”。
- 周期级扫描覆盖与截获窗口：把“是否照到平台”从静态角度门控推进到扫描状态驱动。

### 2. 更丰富的 PRI/PRF 行为

- 固定 PRI 与抖动 PRI 的区分建模。
- 脉组、突发、占空比控制等更丰富的周期级发射节奏。
- 基于 `dt / pri` 之外的体制特征摘要，为后续识别链提供更稳定输入。

### 3. 更强的识别与反欺骗

- 基于 `RF / PW / PRI / scan behavior` 的联合识别，而不是仅依赖当前简化阈值规则。
- 欺骗样式库细化：支持更明确的虚警、错分选、错识别模式。
- 反欺骗先验与稳健关联策略增强，避免复杂干扰下系统性偏乐观。

### 4. ESR 装备参数细化增强

- 极化方式建模：区分接收端极化、发射端极化及其失配损失，不再仅靠频段和功率近似截获条件。
- 精细天线方向图：从当前简化主瓣/副瓣近似推进到二维或表驱动方向图。
- 更细的波束类型与模式差异：把 `ESM / HGESM / RWR` 对扫描、积累、告警和测向链路的影响显式化。
- 更复杂的扫描推进与驻留节奏：把扫描起止边界之外的时间推进逻辑纳入内部状态机。
- 扫描数据率与刷新节奏建模：把“扫描起止角”之外的时间推进速度、刷新周期和告警时效显式纳入模式控制。
- 设备运行态细化：把开关机、模式切换、扫描中心重配置等运行态控制与装备静态参数彻底分层。
- 侦察结果统计摘要增强：系统化输出 `RF / PRI / PW` 的统计区间、稳定性和跨周期演化特征。

## Escalation Boundary

仅当第二阶段的周期级体制建模和识别链仍不足以支撑目标推演时，才考虑更重的“脉冲序列级发射机”建模。  
在此之前，优先保持工程基线可解释、可复现、可测试。

### 5. `common/environment` 抽象准入门槛

- 仅当至少 3 个模块出现**完全相同**的环境运行模式时，再考虑抽取公共环境层。
- 判定标准不是字段名相似，而是输入、状态、输出和错误语义都基本一致。
- 若只是流程外形相似，但业务语义不同，则继续保留各模块内部实现，不上提为公共模块。
