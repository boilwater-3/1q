# 场景原型库（Scenario Archetypes）

战场场景**取材**于真实任务，落到仿真时必须裁剪成"单变量可判定"的几何（见 SKILL.md
步骤 2）。每个原型给：通道组合、被测行为、边界条件检查清单、场景 JSON 参数要点。

裁剪三原则：
1. **一次只验证一个变量**——完整战场多因素耦合，失败无法归因；
2. **几何先验可手算**——场景参数能推出预期周期窗/量级（写预期表的前提）；
3. **基线先行**——新原型先在单通道 + 简单几何上成立，再叠加。

## 原型清单

### 1. 基线巡航（baseline_takeoff_east，现有）

- **通道**：全通道；**被测行为**：端到端链路基线成立（探测→融合→决策）；
- **要点**：目标与平台同速东飞 → 恒在正北侧方 → SAR 正侧视、AR 方位稳定、EOS 扫描
  覆盖——"多通道同时成立"的最简几何；
- **边界检查**：EOS 距离窗 [11.5, 22.9] km（400 m × [1°,2°]）、SAR squint ≤ 门限
  （巡航段）、SBIRS 星下点 FOV、ESR 频率分离（9.5/10.0 GHz）。

### 2. 拦截（迎头/追尾接近）

- **通道**：AR（主）+ EOS/Fusion；**被测行为**：AR 高接近率下的距离门/多普勒处理、
  探测距离窗、融合置信度累积；
- **要点**：目标 v_east 与平台相反（迎头）→ 接近率 ~100 m/s，距离单调减小穿过
  AR 探测窗；可加"目标在 EOS 窗内/外切换"检验生命周期；
- **边界检查**：AR 最大探测距离/径向速度门限（boundaries.md）、EOS 距离窗随平台
  高度；
- **JSON 要点**：改 `targets[].v_east_mps`（负值 = 迎头）、`range_m` 起点放远。

### 3. 目标大机动（逃逸/掉头）

- **通道**：AR（主）+ EOS/SAR；**被测行为**：机动下的跟踪保持/生命周期、EOS 观测
  条件变化、SAR 几何破坏；
- **要点**：目标 `maneuvers[]` 变速（分段匀速，`start_cycle` + 新速度）；对照组目标
  不动以区分机动影响；
- **实测教训（场景 target_maneuver_evasion 归档，2026-08-07）**：**速度跳变不触发
  AR 失跟**——35/100 m/s 转向与掉头迎头（接近率突变 ~100 m/s）均保持跟踪。AR 失跟
  需**探测断链**（miss 积累 → kLost）：目标消失（遮蔽）/出距离窗/RCS 突变，而非
  机动幅度本身。纯机动场景验证的是"跟踪保持 + 观测条件变化"（EOS 探测数下降、
  方位出视场可观测；SAR 成像判定对 ≤6 km 点目标偏移不敏感）；
- **边界检查**：AR kLost 语义（boundaries.md）、EOS 视场/扫描扇区、SAR squint 门控；
- **JSON 要点**：`targets[].maneuvers[]`（绝对速度分段，未指定分量 = 0，须写全；
  start_cycle 严格递增）。

### 4. 多目标饱和（N 目标）

- **通道**：全通道；**被测行为**：ESR 分选聚簇在 N 目标下的假设数、融合关联
  （方位相干门限）、决策门限下的指令流；
- **要点**：N 个目标分布在方位/距离上（保证可分离），中心频率按目标数配置（ESR
  分选需要频率分离才能稳定聚类）；
- **边界检查**：融合 source_weights/方位相干门限（8°）、ESR 频率间隔 > 分选分辨率；
- **JSON 要点**：`targets[]` 数组加条目，`emitter_center_frequency_hz` 逐目标递增。

### 5. 空域清净（无目标）

- **通道**：全通道；**被测行为**：零探测下的假警行为（无目标不应有探测事件）、
  融合空集、决策不下发；
- **要点**：`targets: []`（加载器允许空数组）；**冒烟下限必须置 0**
  （`smoke.min_* = 0`），否则 ctest 冒烟红；
- **实测教训（场景 no_targets_clean_airspace 归档，2026-08-07）**：空场景的判定
  核心是"无探测/无融合/无指令"；**SAR 例外——空场景仍产出 1 条成像产品**
  （cycle 19，SNR=-inf dB）：产品事件 = 孔径成像成功，与点目标存在性解耦，预期表
  应写 1 而非 0；
- **预期**：EOS/SBIRS/AR 无探测事件、SAR 视图目标数 0、fused=0、command 不 issued；
  库日志除 squint 拒绝（按设计拒绝，预期出现）外无其他 ERROR。

### 6. 天基通道专项（SBIRS）

- **通道**：SBIRS（主）+ Fusion；**被测行为**：coasting（目标红外被遮蔽/视场角变化
  时的保持语义）、星下点几何、卫星高度对 FOV/信噪比的影响；
- **要点**：改 `sbirs_satellite.altitude_m`（500 km 基线 → 1000/200 km）或让目标
  移出 FOV 再回来；
- **边界检查**：SBIRS FOV 20°、az/el 为 ECEF 极坐标（与机载方位参考系不同——融合
  方位相干门限无法跨参考系关联，SBIRS 独立成目标，这是已知语义非 bug）；
- **预期亮点**：coasting 事件在目标短暂出视场时出现、回来后续接。

### 7. SAR 成像专项

- **通道**：SAR（主）；**被测行为**：squint 门控边界（几何成立/不成立的临界）、
  链路预算（RCS/功率/增益/距离 → SNR 过 minimum_snr_db）、斜距失配；
- **要点**：改 `sar` 块（功率/增益/场景中心/斜距）或 `targets[].rcs_m2`；
- **边界检查**：squint ≤ max_squint（场景 `sar.max_squint_deg`）、SNR ≥
  minimum_snr_db（sar.json）、场景中心与巡航段几何对齐；
- **预期亮点**：把 RCS 降到 1 m² 以下 → SNR 掉过门限 → 成像不成立（预期拒绝）；
  把场景中心挪离巡航侧方 → squint 全程超限（场景设计问题示范）。

### 8. 电子侦察专项（ESR）

- **通道**：ESR（主）；**被测行为**：辐射源分选（频率分离 → 假设数）、波形参数对
  检测概率的影响（脉冲数/功率）、假设生命周期；
- **要点**：改 `esr` 块波形参数或目标频率（两源频率靠近 → 分选合并为 1 条假设）；
- **边界检查**：中心频率间隔 vs 分选分辨率；KEY 模式下假设事件不落盘（需
  `CA_EVENT_LOG_MODE=all` 观测）——**预期表注明模式可观测性**；
- **JSON 要点**：`esr.pulse_count`（积分脉冲数）、`targets[].emitter_center_frequency_hz`。

### 9. 飞行机动专项（FD）

- **通道**：Flight（主）+ 各传感器；**被测行为**：FD 六自由度机动（起飞/转弯/降落）
  下的传感器几何动态、航点到达判定；
- **要点**：构建时 `ONEQ_ENABLE_FLIGHT_DYNAMIC=ON`；改 `platform.waypoints[]`（航线）；
  注意 FD 起飞段实际航迹（README：hdg 293°→358° 爬升）——传感器预期必须按实际
  航迹算，不能按名义航向；
- **边界检查**：FD 起降语义（不做空中配平）、运动学回退路径行为一致；
- **预期亮点**：转弯段 SAR squint 拒绝 + EOS 方位出扫描扇区 = 按设计拒绝。

### 10. 决策链专项

- **通道**：Fusion + Decision；**被测行为**：置信度门限（`high_threat_confidence`）、
  源权重对置信度的影响、指令只下发一次；
- **要点**：调 `high_threat_confidence`（3.0 → 5.0 指令不下发；→ 1.0 提前下发）；
  调 `fusion.source_weights`（弱化某通道观察置信度变化）；
- **边界检查**：融合置信度 = Σ 判决值 × 质量归一化 × 权重（FusionConfig.h 注释）；
- **预期**：门限提高 → command 不 issued 或推迟到更晚周期。

## 组合建议

- 新场景一律从原型 1（基线）拷贝 JSON 起步，只改被测变量；
- 原型 2/3 先单通道跑通（把其他通道的 `smoke` 下限置 0 免干扰），再加 Fusion；
- 一个场景只服务一个"被测行为"，预期表围绕它写——其余通道写"预期出现/按设计拒绝"
  即可，不展开。
