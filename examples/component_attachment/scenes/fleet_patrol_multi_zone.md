## 结论

**判定：通过**（120 周期冒烟实测；FD 模式需手动跑完整 600 周期复核航点簿记）。本轮实测知识：

1. **多机装配零结构改动**：FlightComponent 自包含（每实例一个 FlightManager），多机 = 每从机一个实体挂组件；场景 `platforms[]` 数据驱动，从机巡航缺省回退主平台；
2. **可视化契约 v2 落地**：platform_track/route_plan 按 aircraft_id 分机（3 机各 120 行），zones.csv 三个区域（多边形 A/C + 圆形 B）直接画进查看器地图；target_truth entity_type=ground 目标 1003 以地面线型标注；
3. **地面目标 = 静止近地运动学点**（alt 0、v=0）：AR 距离门内正常确认（cycle 1，无多普勒依赖问题），SBIRS 以 450 K 温度弱检出（SNR 4.6）后视场外丢失——"地面目标"在传感器面无特殊处理，可视化与场景语义层区分；
4. **SBIRS 凝视质心几何**：三目标分散（东 2/6.2/12.9 km）→ 质心 ≈ 东 7 km，1001/1003 偏离质心 → 视场外间歇（patrol_area_scan 单目标对无此现象）——SBIRS 对偏离星下点目标的可见性与目标群几何相关，属模型行为（基线同类事件先例）；
5. **"目标在区域内"与 SAR 侧视几何天然矛盾**：巡逻扫描线沿目标方向飞（squint ≈ 90°）→ SAR 按设计拒绝（运动学 0 个；FD 起飞转向段侧视扫过目标有 1 个物理真实产品，smoke 置 0 保守）；要 SAR 持续成像需目标在巡逻区外正侧方（patrol_area_scan 设计）。

**原型库回写**（`scenario_archetypes.md`）：多机编队 = `platforms[]` 数组（每机各自 coverage 区域任务）；地面目标 = type=ground + alt 0 + v=0；"目标在区域内"场景的通道窗口：EOS 距离窗下限 11.46 km 使近距目标不可见、SAR squint 拒绝——多通道同时成立的几何窗口需目标群位于巡逻区外缘带（下轮场景设计）。
