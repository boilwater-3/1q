## 结论

**判定：通过**。四点实测知识：

1. **极化真值缺省陷阱**：特征铺样必须按"显式给值才铺维"——极化通道 0 dBsm 是
   合法值，不能用零值判缺省；错误极化维会把综合分拖过门限以下（本场景复现：
   带假极化 0.53 vs 两维 0.79），识别长期停留在 kUnknown；
2. **键空间统一是集成方职责**：RIR 出口①只带库内键（去真值化纪律），组件层按
   结果层归属视图把键重写为外部目标 ID 后，RIR 量测并入与机载传感器同键的融合
   航迹（源通道 5）；归属缺失的周期（如首周期归属表滞后）记录保留库内键；
3. **指定任务完成沿**：识别达成回扫不置 `designation_reverted_to_scan`（该标志仅
   缺席/超时用），完成事件须以 designated_target_id 归零沿判定；
4. 基线场景的融合航迹规模（21-25）由 ESR 假设键既有行为贡献，非本场景引入。
