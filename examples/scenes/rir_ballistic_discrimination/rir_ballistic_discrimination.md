# rir_ballistic_discrimination 期望事件表

## 场景定位

验证 RIR 极化散射矩阵统计特征链（2026-09-03 契约：docs/review 证据矩阵 §3）：
场景层开机一次性载入极化字典（架构 B）→ 每周期按当前视线角裁 ±5° 窗口行 →
库内五量统计（|det S| / Span / 去极化 / 方向角 ψ（圆统计）/ 椭圆率 τ，各
均值+标准差）→ 验收日志"极化特征解算功能测试"双值行。

四类弹道目标各配**合成占位字典**（非甲方实测数据，待原件替换）：
目标类型以极化特征区分——弹头低去极化低起伏、重诱饵中等起伏、轻诱饵小 RCS
高交叉、碎片高去极化高起伏+ψ 大摆动。

字典覆盖：方位 −180°..+180° 步 5° × 俯仰 0°..30° 步 5°（511 行/目标，覆盖弹道弧全程视线角）；窗口 ±5°。

全量试跑实测（2026-09-03，1560 周期，确认周期 736）：去极化均值序 弹头 0.0003 < 重诱饵 0.0049 <
轻诱饵 0.0413 < 碎片 0.1998；ψ 角度散布 碎片 2.2° 远大于其余三类（<0.03°）。

## 期望事件

1. 识别链确认后每周期产出"极化特征解算功能测试"五行双值（均值/标准差）
   与一行目标类型（细分类型判据未冻结，不追加"细分类型="字段——恒仅粗类）。
2. 四目标统计量呈占位设计序：弹头去极化均值最小、标准差最小；碎片去极化
   均值最大、ψ 角度散布最大。
3. 窗口行随视线角变化，标准差非恒 0（与旧"抄 15 遍"占位的本质区别）。
4. SMOKE：识别输出数达到 smoke 下限（试跑标定值见 JSON）。

## 已知边界

- 字典为合成占位值，绝对数值无物理实测依据；相对区分度（类间序）是设计目标。
- 细分类型判决（弹头/重诱饵/轻诱饵/碎片）等甲方判据，当前恒"未判"。
